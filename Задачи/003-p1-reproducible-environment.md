# P1. Окружение не воспроизводится из одного репозитория

## Где

`1_Lab/1_Lab.sln`, `1_Lab/1_Lab.vcxproj`, `StartMain.cpp`, `.gitignore`.

## Проблема

Solution `Debug|x64` собирает project `Release|Win32`. Это меняет и разрядность, и debugging/optimization assumptions. Assimp/stb_image не обеспечены явным manifest с версиями; проект импортирует пользовательские `.props`. Asset paths завязаны на два локальных диска, HLSL - на current working directory.

В Git уже отслеживаются некоторые результаты сборки (`.ilk`, `.pdb`, `.tlog` и др.), а рабочая директория содержит временные каталоги и посторонние файлы.

## Исправление

Починить mapping `.sln`, закрепить язык и конфигурации, затем задать версионируемые зависимости и способ поиска assets от project/content root. Описать runtime DLL для выбранной разрядности. Отдельным согласованным изменением убрать build outputs из индекса и дополнить ignore rules.

## Критерий приемки

Новая рабочая копия имеет документированный путь подготовки и однозначную конфигурацию.

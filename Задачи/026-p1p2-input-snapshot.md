# P1/P2. Mouse offset теряет события, а input lifecycle зависит от draw

## Где

`InputDevice::OnMouseMove`, `Display::WindowProc`, конец полных draw-путей.

## Проблема

`MouseOffset` перезаписывается каждым Raw Input событием. Если за кадр поступило несколько событий, опрос камерой видит только последнее. Сброс offset выполняется внутри конкретного draw; это связывает input с render implementation. `WM_INPUT` также выделяет/освобождает byte array на каждое событие. Явного сброса pressed keys при потере фокуса в оконной процедуре нет.

## Исправление

Frame input snapshot с накоплением относительных смещений и колесика, централизованными begin/end frame, обработкой focus loss. Для Raw Input использовать переиспользуемое хранилище. Производительность allocations вторична по отношению к потере событий.

## Критерий приемки

Все mouse delta события между кадрами учитываются; input lifecycle не зависит от выбранного draw path; потеря фокуса не оставляет клавиши “зажатыми”.

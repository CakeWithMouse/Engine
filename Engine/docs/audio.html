Звук и работа с ним

Импорт, предпрослушивание и игровой код.

Импорт и проверка

  1. В Edit выберите «Сцена → Ресурсы → Импорт аудио…» или «Аудио…» в меню импорта файловой панели.
  2. Выберите WAV, OGG, MP3 или FLAC. Файл копируется в Content/Audio; совпадающее имя получает числовой суффикс.
  3. ПКМ по файлу в Content → «Прослушать». Следующее предпрослушивание останавливает предыдущее. «Остановить звук» завершает его вручную.
  4. Начните с PCM WAV. WAV декодируется встроенным декодером, остальные файлы передаются Windows Media Foundation. Наличие расширения в диалоге не гарантирует доступность декодера.
  5. Импорт не создаёт звуковой компонент сцены. Для игрового события добавьте вызов аудио API из своего компонента.

Готовый компонент

Создайте C++ проект. Скопируйте AudioTutorial.h/.cpp в Source и tutorial.wav из прилагаемых учебных ресурсов в Content/Audio. Выполните Build.ps1, откройте редактор, добавьте «Audio tutorial» из каталога классов, сохраните сцену и нажмите Play. Должен прозвучать короткий тон один раз при BeginPlay.

AudioTutorial.h

#pragma once
#include <Engine/Components/ComponentAnnotations.h>
#include <Engine/Components/GameComponents.h>

ENGINE_COMPONENT("Audio tutorial", "Tutorial.Audio")
class AudioTutorial : public GameComponent {
public:
    void BeginPlay() override;
};

AudioTutorial.cpp

Скачать исходник
#include "AudioTutorial.h"
#include <Engine/MainGame/BaseGameClass/Game.h>
#include <Engine/Runtime/ModuleVfs.h>
#include <Engine/Sound/AudioEngine.h>
#include <filesystem>
#include <stdexcept>

void AudioTutorial::BeginPlay() {
    GameComponent::BeginPlay();
    auto* game = GetGame();
    auto* sound = game ? game->GetAudioEngine() : nullptr;
    if (!sound) return; // The scene also runs on a machine without an audio device.
    const auto file = EngineModuleVfs::Resolve("/Game/Audio/tutorial.wav");
    if (file.empty()) throw std::runtime_error("Import tutorial.wav into Content/Audio");
    const auto id = sound->LoadSound(std::filesystem::u8path(file).wstring());
    if (!id.IsValid()) throw std::runtime_error("Cannot decode tutorial.wav");
    audio::AudioEngine::PlayOptions options;
    options.volume = 0.25f;
    if (!sound->Play2D(id, options)) throw std::runtime_error("Cannot play tutorial.wav");
}

2D, 3D и музыка

Game уже владеет AudioEngine и вызывает Update. GetAudioEngine может вернуть nullptr при недоступном устройстве. SoundId принадлежит конкретному AudioEngine; после его пересоздания загрузите звук заново.

LoadSound принимает физический std::wstring путь. Преобразуйте /Game через EngineModuleVfs::Resolve, затем filesystem::u8path(...).wstring(). Для коротких звуков повторно используйте SoundId. Play2D принимает volume, pitchSemitones и loop. Play3D дополнительно принимает AudioEmitter3D, который копируется: публичного handle для движения уже играющего источника нет.

PlayStream читает музыку потоково и возвращает StreamHandle. StopStream останавливает этот поток. StopAll влияет на все звуки данного AudioEngine. SetListener задаёт слушателя, положение и ориентацию. Используйте mono WAV для первого 3D-примера.

Если звука нет

Проверьте устройство вывода Windows, ненулевой GetAudioEngine, SoundId::IsValid и результат Play2D. Затем проверьте физический путь и PCM WAV. Проигрывание без ошибки не доказывает слышимость на выбранных колонках. После Stop начните новый Play для повторного BeginPlay.

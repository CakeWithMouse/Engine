SaveGame

Движок сохраняет сцену и состояние базовых классов. Наследник добавляет только свои поля. Схема поясняет код; кнопки не запускают движок и не пишут файлы.

Game и GameSession остаются владельцами своих данных. При загрузке отдельно подготавливается Scene; после проверки меняется её содержимое. ComponentId переназначаются через Reference. BeginPlay восстанавливает подписки; OnSaveGameLoaded обновляет кэшированные ссылки.


GPU-ресурсы и callbacks не являются содержимым save-файла. Отказ post-load callback после смены мира оставляет уже загруженную игру на паузе с диагностикой.

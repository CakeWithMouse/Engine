Порядок изучения

  1. Работа редактора — Панели, управление, редактирование и запуск.
  2. Материалы и редактор материалов — От назначения .mat до узлового графа и прозрачности.
  3. Звук и работа с ним — Импорт, предпрослушивание и игровой код.
  4. Работа с кодом — Создание проекта, компоненты, сборка и отладка.
  5. Импорт ассетов — Модели, изображения, аудио и переносимые пути.
  6. Настройка сцены — Объекты, камера, освещение, сохранение и запуск.

Справочник и учебные файлы

API Reference с поиском, объявлениями и примерами работает без сервера. Тематические страницы дополняют справочник рабочими инструкциями.

Исходники туториалов: вращение, ввод, спавн, модели, материалы, HUD, свойства и звук. Ресурсы упражнений: OBJ, PNG и PCM WAV.

В релизе рядом находятся две презентации и четыре самостоятельных проекта: CalmCity, CuriousCity, TiredBomber и AITrash. Начните с README в корне комплекта. Для редактирования кода нужен C++ toolchain, для запуска готовых примеров достаточно Windows x64 с D3D11.

Офлайн-документация. Источник истины: реализация текущего выпуска. Примеры и ресурсы доступны рядом с HTML.

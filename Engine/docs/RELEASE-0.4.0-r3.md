# PainEngine 0.4.0 r3 — комплект из main

Основа комплекта — main `62b4eb4969037ffdd834f08077d1d0037a812ab5`.
В main влита проверенная release/v0.4.0. Числовая версия Runtime и SDK
остаётся 0.4.0; r3 обозначает новую упаковку и обновлённые документы.

## Что входит

- Runtime, Qt Editor и CMake SDK для Windows x64 Release с Jolt и Assimp.
- BasicExamples, Pong, SunGame, Battle, Katamari и RuntimeExample.
- AiTutorial и RepairCorridor с готовой DLL и исходниками стратегии.
- Офлайн-справка, руководства, лицензии и отчёты о проверках.
- GameExecutable.exe и EngineCommandlets.exe из MSBuild для экспорта и CLI.

Запуск: [краткая инструкция к комплекту](DISTRIBUTION-QUICKSTART.md).
HTML-страница выпуска: [0.4.0 r3](release-0.4.0-r3.html).

## Изменения относительно r2

Функциональных изменений движка после r2 нет. Сохранены те же проверенные
бинарники и SDK; их SHA256 записываются в RELEASE-MANIFEST.json. Документация
теперь указывает на выпуск из main и содержит отдельную инструкцию установки,
создания проекта, пересборки стратегии и проверки архива.
Архивы первого выпуска и r2 сохраняются отдельно.

В комплект вошли прежние исправления:

1. Mesh-коллайдер учитывает отражение и полную матрицу родителя.
2. Неиндексируемые вершины не меняют выпуклую оболочку и массу тела.
3. Быстрые операции с ассетами создают разные резервные папки.

Подробности — [изменения r2](RELEASE-0.4.0-r2.md) и
[руководство по физике](PHYSICS.md). Static Mesh сохраняет проёмы;
Dynamic/Kinematic Mesh использует выпуклую оболочку и заполняет вогнутости.

## Совместимость

Module API5, Edit API6 и SceneFormat3 сохранены. C++-проекты с более ранней
сборки 0.4.0 пересобираются согласованным SDK: PhysicsBodyDesc расширен
указателями на геометрию. При переносе с r2 в r3 пересборка из-за ABI не нужна.
Старые Runtime без Mesh не читают shape:"mesh", хотя номер формата сцены тот же.
Обновляйте копию проекта и сохраняйте исходные сцены.

## Проверки

Регрессия движка унаследована от неизменённого r2: Engine86/86 на MSBuild
и CMake, AI58/58, CTest3/3, внешний SDK2/2, Core/Host/Ui и native UI/API.
Прежний автор стратегии проверил игровые Mesh-сценарии, сохранение настроек
между сессиями, MSBuild/CMake, свежую пересборку исходников и Game.exe60.

Результаты проверок именно новой упаковки и её хеши —
[отчёт r3](../../Agent/Playtests/2026-11-18-0.4.0-r3-package/report.md).
Готовая папка прошла 24/24 проверки. Новая инструкция пересборки стратегии
повторена на чистой распаковке в Unicode-пути: CMake Build, активация DLL
и Runtime60 прошли. Все 182 бинарных файла и 366 файлов SDK совпадают с r2.
Внутри ZIP VALIDATION.json и Validation содержат проверку полной папки;
рядом с архивом .zip.validation.json содержит также результат чистой распаковки.

Ручной Inspector-проход остался partial: инструмент не получил окно.
Столкновения импортированной сцены после reopen не запускались;
сохранение параметров и процедурные Mesh-столкновения проверены отдельно.
Linux/macOS/clang-cl и другие мониторы этим комплектом не проверялись.

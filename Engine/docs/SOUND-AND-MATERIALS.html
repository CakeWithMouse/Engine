Перед началом

Открой проект в режиме Edit

Останови Play и открой сцену. Импорт ресурсов и предпрослушивание звуков выполняются в режиме редактирования. Для материала выбери объект с геометрией — например, куб.

Где лежат ресурсы

Content/Audio — импортированное аудио.
Content/Materials — материалы, созданные из инспектора.
Content/Textures — импортированные текстуры.

Что значит /Game

/Game/Audio/click.wav — виртуальный путь к Content/Audio/click.wav текущего проекта. В редакторе используются такие пути; низкоуровневый аудио API принимает физический путь.

01 / Звуки

Сначала услышь файл в редакторе

  1. Импортируй звук

    Выбери Сцена → Ресурсы → Импорт аудио…. В файловой панели также есть меню импорта с пунктом Аудио…. Выбери файл .wav, .ogg, .mp3 или .flac.

  2. Найди копию в проекте

    Файл копируется в Content/Audio. Если имя занято, импорт создаёт новое имя с числовым суффиксом. Используй фактическое имя импортированного файла.

  3. Нажми «Прослушать»

    В файловой панели нажми ПКМ по аудиофайлу внутри Content → Прослушать (Play Audio Preview). Это обычное 2D-прослушивание. Следующий запуск предпрослушки останавливает предыдущий звук.

  4. Останови предпрослушивание

    ПКМ в файловой панели → Остановить звук (Stop Audio Preview). Для этих действий оставайся в Edit; Play и Pause не подходят.

Импорт ещё не означает воспроизведение в игре. Он добавляет файл в проект. Чтобы звук срабатывал при выстреле, нажатии или событии сцены, вызови аудио API из игрового кода.

WAV обрабатывается отдельным декодером. Остальные форматы идут через Windows Media Foundation: наличие расширения в диалоге импорта не гарантирует, что конкретный файл декодируется на машине. Если прослушивание не удалось, начни проверку с обычного PCM WAV.

Какой способ воспроизведения выбрать

ЗадачаВызовОсобенность
Кнопка, уведомление, короткий эффектLoadSound → Play2DЗвук целиком загружается в память. Загрузи один раз и повторно используй SoundId.
Короткий звук в точке мираLoadSound → Play3DПередаётся источник AudioEmitter3D. Для первого опыта используй mono WAV.
Фоновая музыкаPlayStreamПотоковое чтение; возвращает StreamHandle для остановки конкретного потока.

Пример: короткий 2D-эффект

Ниже вспомогательный класс для игрового кода. Вызови Load после инициализации Game, а PlayClick — в обработчике нужного события. Передай абсолютный путь к импортированному WAV.

#include <Engine/MainGame/BaseGameClass/Game.h>
#include <Engine/Sound/AudioEngine.h>

struct UiSounds
{
    audio::AudioEngine::SoundId click{};

    bool Load(Game& game, const std::wstring& absoluteWavPath)
    {
        auto* sound = game.GetAudioEngine();
        if (!sound) return false;
        click = sound->LoadSound(absoluteWavPath);
        return click.IsValid();
    }

    bool PlayClick(Game& game)
    {
        auto* sound = game.GetAudioEngine();
        if (!sound || !click.IsValid()) return false;
        audio::AudioEngine::PlayOptions options;
        options.volume = 0.6f;
        options.pitchSemitones = 0.0f;
        options.loop = false;
        return sound->Play2D(click, options);
    }
};

Game уже создаёт аудиодвижок и вызывает его Update(). При использовании GetAudioEngine() повторная инициализация не нужна. Нулевой указатель означает, что аудио недоступно. SoundId принадлежит конкретному аудиодвижку: при его пересоздании загрузи звук заново.

Эффект в точке мира

Здесь effect — ранее загруженный и проверенный SoundId. Координаты источника задаются в системе координат сцены.

auto* sound = game.GetAudioEngine();
if (sound && effect.IsValid())
{
    audio::AudioEmitter3D emitter;
    emitter.position = {5.0f, 0.0f, 2.0f};
    audio::AudioEngine::PlayOptions options;
    options.volume = 0.8f;
    const bool played =
        sound->Play3D(effect, emitter, options);
    // Проверь played в своей обработке ошибок.
}
Что учитывать в текущем 3D API

Game обновляет слушателя по позиции и ориентации FirstPlayer. Play3D копирует emitter; изменение исходной переменной после вызова не двигает уже запущенный источник. Публичного handle для перемещения или индивидуальной остановки такого звука сейчас нет. StopAll() остановит все звуки и потоки этого аудиодвижка. При недоступном X3DAudio 2D-звук и стриминг продолжают работать, а пространственная обработка отключается.

02 / Редактор материалов

Первый материал на объекте

  1. Выбери объект

    В инспекторе открой карточку Материал. Если слот пуст, нажми Редактировать: редактор создаст материал в Content/Materials, назначит его объекту и откроет окно.

  2. Или создай материал отдельно

    В файловой панели: ПКМ по папке → Новый материал…. Например, назови его Paint. Допускаются латинские буквы, цифры, _, - и .. Появятся Paint.mat и Paint.hlsl.

  3. Настрой вид

    В новом материале доступны параметры Tint и Gloss, а также текстура BaseMap. Выбери цвет Tint и текстуру BaseMap. Посмотри результат на Сфере, Кубе или Плоскости через список «Форма».

  4. Сохрани материал

    В окне материала нажми Сохранить или Ctrl + S. Проверь строку состояния и список ошибок. Изменения должны сохраниться без ошибки записи.

  5. Назначь и сохрани сцену

    Если материал создан отдельно: выбери объект, затем в файловой панели ПКМ по .mat → Назначить материал. Альтернатива: в карточке «Материал» нажми Выбрать…. После назначения вернись в основное окно и выбери Сцена → Сохранить сцену.

Открыть и назначить — разные действия. Двойной щелчок по .mat открывает редактор. Назначение меняет материал выбранного объекта. Если несколько объектов используют один .mat, правка этого ресурса затронет их все.

Что находится в окне

Порог альфыДоступен для masked. Начни с 0.5, затем настрой границу вырезания.

Собираем без HLSL

Текстура × цвет → материал

Нажми Нодовый граф в верхней панели и подтверди создание. Появятся BaseColor, Specular и «Выход материала». Существующий HLSL заменяется кодом графа; до сохранения переход можно отменить кнопкой «Откатить».

Texture2D · RGB
ColorParam · RGBИзображение и оттенок
→
Multiply · A × BУмножение цвета
→
MaterialOutput · AlbedoЦвет поверхности
  1. Добавь ноды

    Нажми + Нода, Tab или ПКМ по пустому холсту. Найди Texture2D («Текстура») и Multiply. BaseColor уже есть в стартовом графе.

  2. Выбери текстуру

    ПКМ по ноде текстуры → Выбрать текстуру…. Выбери файл из проекта или внешний файл: внешний импортируется в Content/Textures. Для первого опыта удобно взять PNG или JPG.

  3. Соедини выходы со входами

    Перетяни связь: Texture2D.RGB → Multiply.A, BaseColor.RGB → Multiply.B, Multiply.Out → MaterialOutput.Albedo. Замени прежнюю прямую связь BaseColor → Albedo. Для снятия связи потяни подключённый вход.

  4. Измени цвет и проверь результат

    Открой свойства BaseColor через ПКМ. Белый сохраняет цвет текстуры; другой цвет тонирует её. Связь Specular.Value → Specular можно оставить. Граф применяется автоматически после короткой задержки.

  5. Сохрани

    Нажми Сохранить. Рядом с материалом появится Paint.mat.graph.json. Он нужен, чтобы позже продолжить редактирование нод.

Быстрый старт: Готовые графы → Textured Color создаёт схему текстуры с цветом. Есть также Animated Neon, Gold и Scrolling Energy. Выбор готового графа заменяет текущий после подтверждения.

Входы «Выхода материала»

Текущий граф использует поля модели освещения движка на основе Блинна — Фонга. У него есть Specular и AmbientModel; рецепты из редакторов с Metallic/Roughness нужно адаптировать.

ВходЧто подключать
Albedo · float3Основной RGB-цвет или результат обработки текстуры.
Alpha · floatАльфа-канал или число. Для видимого эффекта выбери masked либо подходящий режим прозрачности.
Specular · floatВес зеркальной составляющей; в стартовом графе 0.5.
AmbientModel · floatПараметр модели фонового освещения движка.
Emissive · float3Добавляемый цвет свечения. Для примера начни с готового Animated Neon.
Normal · float3Нормаль поверхности. Для normal map используй ноду NormalMap и подключи её Normal к этому входу.

Пресеты и обмен с ИИ

Готовые графы → Сохранить текущий как готовый… сохраняет пресет в Content/MaterialGraphs.

Копировать для ИИ помещает в буфер JSON графа и описание нод. Вставь их в чат, опиши эффект, скопируй ответ и нажми Вставить из ИИ. Проверь граф, текстуры и ошибки перед сохранением.

Почему текстура в ноде есть, а в материале её не видно?

Неподключённая к выходу нода может хранить выбранную текстуру, но не создавать рабочий слот в скомпилированном материале. Подключи её к нужному входу выхода материала. Проверь UV модели и режим смешивания, если используешь Alpha. Имена параметров должны быть допустимыми HLSL-именами; при «redefinition» переименуй конфликтующую ноду.

Для работы с кодом

Тот же материал через HLSL

В режиме графа вкладка HLSL (из графа) показывает сгенерированный код и недоступна для ручного редактирования. Нажми Перейти на код: граф удалится, текущий HLSL останется для ручной правки. Обратное создание графа заменит код стартовым графом — автоматического перевода произвольного HLSL в ноды нет.

Для простого материала без текстуры замени содержимое вкладки HLSL этим примером и нажми «Сохранить». Параметры Tint и Gloss появятся в панели материала.

cbuffer MaterialParams : register(b1)
{
    float4 Tint = float4(0.25f, 0.8f, 0.45f, 1.0f);
    float Gloss = 0.5f;
};

void Surface(MaterialInput i, inout MaterialOutput o)
{
    o.Albedo = Tint.rgb;
    o.Alpha = Tint.a;
    o.SpecularWeight = Gloss;
}

Для текстуры в режиме кода есть Добавить текстуру…: инструмент добавляет слот и соответствующую обработку в HLSL. Если шейдер не использует текстуру при текущих настройках, компилятор может убрать её слот. Глобальная команда Сцена → Перекомпилировать шейдеры доступна по F6.

Что сохраняется и что откатывается

Файл / действиеНазначение

Граф использует файлы HLSL и JSON уже во время живого предпросмотра. Для отказа от опыта используй штатные «Откатить» или отказ от сохранения при закрытии. В режиме ручного HLSL некоторые операции с текстурными слотами также сразу записывают код; для важных исходных материалов заранее сохрани копию файлов.
Диагностика

Если что-то не получилось

Нет пункта «Прослушать»

Убедись, что выбран аудиофайл поддерживаемого расширения внутри Content и открыт игровой модуль с расширением AudioPreview. В старом модуле предпрослушивание скрывается: пересобери модуль с актуальным SDK. Для запуска вернись в Edit.

Файл импортировался, но звука нет

Проверь устройство вывода и громкость Windows, затем попробуй PCM WAV. Импорт проверяет расширение, а декодирование происходит при воспроизведении. В C++ проверяй GetAudioEngine(), SoundId.IsValid(), возвращаемое значение Play2D/Play3D и StreamHandle.IsValid(). Передавай физический путь, а не строку /Game напрямую.

Кнопки материала недоступны

Открой проект и сцену, выбери объект с геометрией и останови Play. Если карточка сообщает, что материалы требуют обновления игрового модуля, пересобери модуль с актуальным SDK. Редактор открывает материалы только из Content текущего проекта.

В превью материал изменился, а объект остался прежним

Проверь путь .mat в карточке выбранного объекта. Открытие файла двойным щелчком не назначает его объекту. Назначь через «Выбрать…» или «Назначить материал», затем сохрани материал и сцену отдельными действиями.

Пропала прозрачность или вырез

Подключи Alpha к выходу материала и выбери правильное «Смешивание». Непрозрачный режим не использует альфу для прозрачности. Для masked настрой порог и убедись, что у текстуры есть нужный альфа-канал.

Ошибка компиляции, материал выглядит неверно

Открой список ошибок снизу и дважды нажми на сообщение. Проверь типы входов, имена параметров и связи до выхода материала. В режиме кода проверь Surface и MaterialParams. Исправь ошибку, сохрани и убедись, что строка состояния показывает «Шейдер скомпилирован».

После повторного открытия изменения исчезли

Материал и сцена сохраняются отдельно. Проверь, что «Сохранить» в окне материала завершилось без ошибки, а назначение .mat сохранено в сцене. При передаче проекта переноси .mat, .hlsl, .mat.graph.json и используемые текстуры; один .mat не содержит их данные.

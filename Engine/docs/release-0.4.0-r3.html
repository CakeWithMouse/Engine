PainEngine 0.4.0 · Windows x64 · 18 ноября 2026

PainEngine 0.4.0 r3 из main

Готовый комплект Windows x64 после слияния release/v0.4.0 в main.

Версия и состав

Основа: main 62b4eb49. Версия Runtime и CMake SDK — 0.4.0; r3 обозначает упаковку и документы. Код и проверенные бинарники совпадают с r2.

В комплекте Runtime, Qt Editor, SDK, Jolt, Assimp, пять игр, RuntimeExample, AiTutorial и RepairCorridor. История, исходники стратегии и лицензии включены.

Первый запуск

  1. Распакуйте ZIP целиком в новую папку и откройте EngineLauncher.exe.
  2. Выберите готовую игру или редактор. Для примеров компилятор не нужен; требуется Windows x64 с Direct3D11.
  3. Создайте проект в отдельной папке. Сохраняйте сцену Ctrl+S; после Stop возвращается исходная Edit-сцена.

Подробная инструкция: установка, C++, пересборка стратегии, экспорт и SHA256.

Исправления и совместимость

В main включены исправления отражённых Mesh-коллайдеров, влияния лишних вершин на hull/массу и совпадения backup-папок ассетов. Static Mesh сохраняет отверстия; Dynamic/Kinematic использует выпуклую оболочку.

Module API5, Edit API6 и SceneFormat3 сохранены. Для более раннего 0.4.0 пересоберите C++-проект согласованным SDK. Старые Runtime не понимают Mesh-сцены. Переход с r2 на r3 ABI не меняет.

Проверки и ограничения

Неизменённые бинарники унаследовали регрессию r2: Engine86/86, AI58/58, CTest3/3, внешний SDK2/2, Core/Host/Ui и native UI/API. Новые проверки пакета записаны в VALIDATION.json и соседний с ZIP .zip.validation.json; хеши — SHA256SUMS.txt и .zip.sha256.

Ручной Inspector-проход и столкновения импортированной сцены после повторного открытия остались partial. Сохранение настроек и процедурные Mesh-сценарии проверены отдельно. Другие ОС и мониторы не проверены.

ИИ

Общий инструмент на state machine как в Unreal и стратегический слой поверх него.

Это предложение: ни один новый класс со схемы пока не существует. Архитектура и этапы — в AI-DESIGN.md, примеры кода — в AI-CPP-GUIDE.md.

3. Иерархический автомат

Стражник из руководства. Родитель сам не выполняется и входит в первого подходящего ребёнка, его задачи работают, пока активен любой ребёнок. Старт: Patrol, затем Walk.

4. Как написать ИИ на C++

Четыре шага в коде. Подсистему объявлять не нужно, регистрировать классы вручную тоже.

  1. ПамятьКлючи: имя и тип значенияAi::Key<Ai::ObjectRef> Target{"Target"};
  2. Задачи и условияТолько то, что относится к правилам игрыclass Attack : public Ai::Task<AttackData>
  3. АвтоматСостояния, задачи и переходыchase.GoTo("Hit").OnSucceeded();
  4. ЮнитНастройка чувств и запуск автоматаclass Guard final : public AiCharacter
  5. СборкаГенератор сам добавит класс в палитру, а поля — в инспекторENGINE_COMPONENT("Стражник")
  6. Play и отладкаСостояние над юнитом и журнал переходовai.ActiveState(); ai.History();

5. Один кадр

ИИ встаёт в существующий шаг Session->Tick, цикл кадра не меняется. В Pause и в Edit он не работает.

  1. PreUpdate
  2. ActionInput.Tick
  3. Session->Tick
  4. Controller->Tick
  5. UpdateCamera
  6. TickComponents
  7. RenderFrame

Внутри Session->Tick встроенная подсистема вызывает Ai::World::Tick(dt):

  1. Снять позицииУбрать контроллеры удалённых объектов
  2. Обновить соседейSpatialHash пересобирается один раз
  3. ВосприятиеПроверки видимости по кругу, с бюджетом
  4. ПодуматьСлужбы, задачи, переходы
  5. Поиск в рамках бюджетаA*, поля и запросы, не больше N за кадр
  6. Желаемая скоростьИз пути, из поля или к своему слоту
  7. ИзбеганиеРазведение с соседями, запрет занятых клеток
  8. ЗаписатьCharacter::Move или SetInstancePosition

6. Как приказ становится движением

Различаются только источник направления и способ записи. Автоматы, задачи и избегание общие.

Одиночный юнит (Character)
Толпа: отряд из MeshInstance
Кто решает
Задача автомата: Ai::Tasks::MoveTo
Приказ
Controller::MoveTo(point)
Group::MoveTo(point)
Поиск
A* по NavGrid, запрос встаёт в очередь
Волна от цели, одно поле на цель и класс размера
Результат
Ломаная, спрямлённая по прямой видимости
Направление в каждой клетке; боец читает его за O(1)
Следование
К очередной точке. Нет продвижения — новый запрос
По полю, пока свой слот не станет виден напрямую
Избегание
Разведение через SpatialHash, запрет занятых клеток через NavGrid
Запись
Character::Move(direction, dt) и поворот
SetInstancePosition, SetInstanceYaw
Ответ автомату
Статус: Waiting, Moving, Arrived, Unreachable, Stuck
Цена растёт с
числом юнитов: один поиск на каждого
числом разных целей: от числа бойцов почти не зависит

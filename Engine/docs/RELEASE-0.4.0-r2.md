# PainEngine 0.4.0 — повторная сборка r2

Основа: main `48901772` (PR31), объединённый с release/v0.4.0 в `ffa76363`.
Версия runtime и SDK остаётся `0.4.0`; новый ZIP имеет суффикс `r2`.
Предыдущий архив и результаты первого цикла сохранены отдельно.

## Новая Mesh-физика

- В инспекторе появилась форма «Меш (сложная)» / Mesh (complex).
- Static использует точные треугольники CPU-геометрии и сохраняет проёмы.
- Dynamic и Kinematic используют одну выпуклую оболочку; вогнутости заполняются.
- Настройка сохраняется в Scene JSON как `shape:"mesh"`, в PhysicsObject v1 — `shapeType=3`.
- C++ `PhysicsBodyDesc` расширен указателями на геометрию; проекты пересобираются новым SDK.

[Практическое руководство, примеры и ограничения](PHYSICS.md).
Сцены с Mesh не читаются старым runtime, несмотря на прежний SceneFormat3.
Обычные формы и базовые Module5/Edit6 не изменены.

## Исправления при повторной проверке

1. Mesh-коллайдер терял отражение и часть родительского преобразования.
   Теперь вершины переносятся из мировой геометрии в координаты тела полной матрицей.
   Сравнение визуального и физического raycast проходит для обычного, зеркального
   и повёрнутого неравномерно масштабированного родителя.
2. Неиндексируемая вершина меняла выпуклую оболочку и массу движущегося тела.
   Теперь используются только вершины пригодных треугольников. Битые индексы,
   вырожденная и нечисловая геометрия отбрасываются до создания Jolt shape.
3. Две быстрые операции с ассетами могли переиспользовать резервную папку
   из-за грубого таймера Windows. Папки теперь создаются уникально; регрессия
   сохраняет 32 отдельных backup для 32 последовательных переносов.

Обновлены тесты Mesh в Scene/C ABI и проверка значения 3 в инспекторе после
смены языка. Документация формата сцен, Edit API, справочник C++ и офлайн-страницы
приведены к новому поведению.

## Проверка и комплект

Результаты нового цикла учитываются отдельно от первого:
Engine86/86 на MSBuild и CMake, AI58/58, CTest3/3, внешний SDK2/2,
Core/Host/Ui и целевые native UI/API-проверки прошли. CMake Unicode workflow
подтвердил пересборку и сохранение рабочей DLL при ошибке компиляции.
[сборки и регрессия](../../Agent/Playtests/2026-11-18-0.4.0-r2-release/report.md),
[прежний автор стратегии](../../Agent/Playtests/2026-11-18-0.4.0-strategy-r2/report.md).
В архив входят свежие Runtime/Editor/SDK, игры, новая копия RepairCorridor,
руководства, исходный архив стратегии и отчёты. Комплект проверяется до упаковки
и после распаковки; SHA256 ZIP сохраняется рядом.

Готовая папка прошла 24/24 проверки, включая C++ SDK, экспорт и запуск Game.exe.
В комплект добавлены GameExecutable.exe и EngineCommandlets.exe из MSBuild:
сырая CMake build-папка не содержит эти вспомогательные программы.
Непосредственная проверка инспектора агентом осталась partial из-за недоступного
окна; native UI/API-регрессии нового Mesh-пункта прошли отдельно.

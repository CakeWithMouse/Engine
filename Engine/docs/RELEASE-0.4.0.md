# PainEngine 0.4.0

Ветка `release/v0.4.0` создана 18.11.2026 из актуального `main` (`5458f022`).
Номер runtime и SDK — `0.4.0`. Здесь перечислены изменения после 0.3.1,
включая интеграцию стратегии и новые правки `114b1b69..5458f022`.

## Сборка, SDK и готовая игра

- Добавлены CMake 3.24+ и Ninja: Windows desktop с MSVC/clang-cl,
  переносимое ядро и ComponentGenerator для Windows/Linux/macOS.
  Полный runtime и редактор по-прежнему требуют Windows x64/D3D11.
- CMake SDK экспортирует `PainEngine::Core` и `PainEngine::Engine`.
  Редактор распознаёт его `Sdk.json` и создаёт CMake-проект при включении C++.
  Прежние MSBuild SDK и проекты поддерживаются отдельно.
- В CMake Assimp и Jolt включаются явно. Для стратегии с физикой необходим
  Jolt; без него используется заглушка. Shared DLL и import libraries
  включаются в соответствующий SDK.
- Сборка C++ проверяет содержимое файлов и сохраняет активный модуль при
  ошибке кандидата. Исправлена передача Unicode-путей в скрытые MSVC/CMake-процессы.
  При релизной проверке устранено смешивание старого `cl.exe` из CMake SDK
  с заголовками более нового установленного MSVC.
- «Собрать EXE…» в лаунчере и редакторе создаёт поставку с `Game.exe`.
  Пользовательский C++-модуль предварительно собирается с Release SDK.

Команды и зависимости: [CMAKE-BUILD.md](CMAKE-BUILD.md).
Экспорт: [RELIABLE-WORKFLOW.md](RELIABLE-WORKFLOW.md).

## Редактор и материалы

- Карточка «Материал» показывает компактные строки слотов модели:
  назначение `.mat`, выбор и перетаскивание из Content Browser. При большом
  числе слотов появляется фильтр. Части импортированной модели разделяются
  по слотам, чтобы материал одной части не менял остальные.
- Карточки инспектора получили общий стиль и кнопки справки. Длинные пути
  сокращаются в пределах карточки; выбор ресурсов унифицирован для HUD,
  скриптов и автоматов ИИ. Исправлена нормализация путей `.vscript`/`.fsm`.
- Прокрутка над числовыми полями и списками не меняет значение случайно.
  Улучшены SVG-иконки, разделители и стрелки папок при высоком DPI.
- Отдельные окна инструментов поддерживают сворачивание через панель задач.
  Исправлены начальные значения списков физики в инспекторе.
- Правка свойств точечного света сохраняет включённые тени.
  Обновлены заставка и значки; значок лаунчера доступен и для старых проектов.

## Стратегия, ИИ и камера

- Диагностика ИИ во вьюпорте показывает навигационную сетку, clearance,
  стоимость, маршруты, поле направлений, места группы и восприятие.
  Панель, легенда слоёв, прокрутка и закрепление переработаны.
  Программный интерфейс — `Engine.Scene.AiDiagnostics` v1.
- Направляющие камеры показывают направление, границы кадра и Near/Far;
  параметры расстояния доступны в инспекторе.
  Исправлен выбор значка и цвета игровой камеры, заданной типом объекта.
- В игровых прогонах Repair Corridor исправлены передача плотности в Jolt,
  навигация группы вокруг препятствий, сопровождение движущейся цели,
  AUTO-радиус диагностики и застревание после смены строя у барьера.
- Исходники и отчёты пяти этапов стратегии сохранены отдельно: выделение
  рамкой, Shift, групповые приказы/атака, линия/колонна и диагностика.
  Эти механики принадлежат тестовой игре, а не универсальному RTS-редактору.

## Совместимость и обновление проекта

Формат сцены — 3, Module API — 5, Edit API — 6; поддерживаются Edit API 4/5/6.
Базовые версии ABI не повышены. Необязательное расширение диагностики
обнаруживается отдельно. Новые потребители должны проверять его наличие.

Сохраните исходный проект и обновляйте копию. C++-игры пересоберите с SDK
0.4.0; не смешивайте библиотеки, заголовки, конфигурации и несовместимые C++ ABI.
Дата `2026.11.11.0` в старых отчётах относится к предыдущей сборке main.
Не меняйте компилятор в существующем CMake cache — создайте новый каталог сборки.
Перед распространением игры проверьте её экспорт отдельно от запуска в редакторе.

## Проверка этой ветки

На Windows x64 прошли свежие MSBuild/CMake-сборки, Engine83/83, AI58/58,
Core1105, Host165, весь UiTests, native-проверки диагностики и камеры,
CMake3/3 и внешний потребитель SDK2/2. Автор стратегии повторил миграцию,
игровые приказы, экспорт/Game.exe, CMake-сборку с Unicode-путём и операции
со слотами материалов. Его непосредственный проход по панелям ограничен
недоступностью окна через CUA; автоматическое покрытие учитывается отдельно.
Linux, macOS и clang-cl в этой проверке не запускались.

[релизная проверка](../../Agent/Playtests/2026-11-18-0.4.0-release/report.md).

## Готовая поставка

Архив `PainEngine-0.4.0-win64.zip` содержит Launcher, Runtime, Editor,
командлеты, CMake SDK, Jolt/Assimp, необходимые Qt/OpenSSL/CRT DLL,
пять отдельных игр, RuntimeExample и учебные проекты AiTutorial/RepairCorridor.
Распакуйте его целиком и запустите `EngineLauncher.exe`.
`Documentation.html` открывает актуальные HTML-руководства и API Reference.
Исторические презентации и старые runtime в архив не включены.

Комплектность, x64/DLL-зависимости, офлайн-ссылки, запуск примеров/редактора,
создание C++-проекта новым SDK и экспорт проверяются из отдельной папки
без DLL из рабочего checkout в PATH. Результат — `VALIDATION.json`;
состав и версии — `RELEASE-MANIFEST.json`, контрольные суммы — `SHA256SUMS.txt`.
Рядом с ZIP сохраняется его файл `.sha256`. После упаковки выполняются
проверка CRC и повторный запуск из распакованного архива.

Пакет собирается `Engine/BuildSupport/New-ReleaseArchive.py` из готовой
CMake Release-сборки и проверяется `Test-ReleasePackage.ps1`.
Исторический `New-Release.ps1` с RAR-базой для этого ZIP не используется.

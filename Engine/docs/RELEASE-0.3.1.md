# PainEngine 0.3.1

Ветка `release/v0.3.1` объединяет `release/v0.3.0` (`3fc1ef9`) и main после
слияния PR №25 (`bbeb206`). Дата выпуска: 14.11.2026.

Добавлены физика Jolt, примитивные коллайдеры, параметры тел в инспекторе,
настройки физического мира и сохранение параметров тела в сцене. Сохранены
исправления замены моделей из 0.3.0, скрипты, автоматы ИИ и импорт моделей.
[Руководство по физике](PHYSICS.md) описывает сценарий и ограничения.

При интеграции исправлены отсутствующий VcpkgRoot.props, дубли тестов и методов
инспектора, а также сборка заглушки без Jolt. Формат сцены и версии базовых ABI
не повышены. C++ проекты требуют пересборки с согласованным SDK.
Дополнительно исправлены влияние плотности на массу тела, `SetActive(false)`,
инициализация API в тестовом host и единая линковка/доставка Jolt для потребителей
Engine. SDK помечает включённый Jolt и поставляет его import library.

Заставка Launcher сохранена из поставки 0.3.0: исходники проверены по SHA-256
её RELEASE-MANIFEST.json и включены в новую ветку. Исходная рабочая копия не изменялась.

## Поставка

Пакет `PainEngine-0.3.1-win64.zip`: Launcher, Runtime, Editor, командлеты,
Jolt.dll и Assimp, полный Release SDK, игры и исходники учебных проектов,
лицензии, офлайн-справка и руководства Markdown.
Blender не входит в комплект. Для импорта .blend установите Blender 4.2+; при необходимости задайте PAINENGINE_BLENDER полным путём к blender.exe.
Презентации обновлены для 0.3.1: туториал r13 (98 слайдов) и изменения r6
(9 слайдов), оба в PPTX и PDF. Раздел физики включает настоящие снимки Qt-панелей,
практику падения на пол, C++ API и ограничения. В дистрибутиве оставлены только эти редакции в папке Presentations.
История редакций хранится в исходном репозитории.

Первоначальный пакет: 43 проверки — PASS. Проверены шесть игр и пять режимов редактора,
новый проект и C++-проект, пересборка шести учебных проектов, AiTutorial,
проекты SDK v142/v143/v145, комплектность Jolt и офлайн-справка.
Проверка bundled Blender относится к первоначальной комплектации. В облегчённом
архиве Blender удалён по запросу пользователя, остальные бинарные файлы сохранены.
Подробности — VALIDATION.json и папка Validation в дистрибутиве.
Логи сборки и проверок: `O:/Engine/ReleaseChecks/0.3.1`.
Исходная рабочая копия `O:/Engine/Engine` и предыдущий архив сохранены.

Материалы и редактор материалов

От назначения .mat до узлового графа и прозрачности.

Первый материал

  1. В Edit выберите куб. В инспекторе откройте «Материал» и создайте новый материал. Он попадёт в Content/Materials. Также доступны команды «Новый материал…» и «Редактировать материал» в файловой панели.
  2. Измените цвет и параметры в окне материала. Для текстуры выберите BaseMap и изображение из Content/Textures. Назначение должно появиться на превью и объектах, использующих этот .mat.
  3. Нажмите «Сохранить» в окне материала: сохраняются .mat и HLSL. Ctrl+S в основном окне сохраняет сцену со ссылкой на материал, это отдельная операция.
  4. Закройте и повторно откройте сцену. Проверьте материал на объекте. Пурпурно-чёрная шахматка означает ошибку ресурса или компиляции, причину ищите в окне материала и журнале.

Узловой граф

  1. Нажмите «Нодовый граф». Рядом с .mat появится .mat.graph.json, HLSL будет генерироваться из графа.
  2. Tab, пробел, ПКМ по пустому месту или «+ Нода» открывают поиск. Найдите Color, соедините его выход с цветом Surface. Двойной щелчок по ноде открывает параметры.
  3. Тяните связь от выхода ко входу. У входа одна связь, циклы запрещены. F показывает весь граф или выделение. Колесо меняет масштаб, средняя кнопка или ПКМ перемещают холст.
  4. Ctrl+Z/Ctrl+Y меняют историю графа. Копирование и вставка переносят выделенные ноды. Сохраните материал и граф; проверьте результат после повторного открытия.

Текстуры, нормали и слоты

BaseMap задаёт цвет. NormalFromMap использует tangent basis MeshVertex, включая знак зеркального масштаба; skeletal-формат использует производные UV. Для multi-material модели меняйте отдельный source material ID в свойствах модели. Общий материал объекта перекрывает все слоты. Номера слотов могут идти с пропусками.

Opaque рисует непрозрачную поверхность, Masked отбрасывает пиксели по AlphaClip, Translucent смешивает цвет, Additive добавляет свечение. В версии 2026.11.07.7 первые 16 глубин прозрачных пересечений обрабатываются по пикселям. Дальний остаток и legacy/custom PS имеют ограничения сортировки. Это не неограниченная точная прозрачность.

Изменение общего Material влияет на всех владельцев. SetRenderState требует Compile. SetParameter возвращает false для неизвестного параметра. После правок файлов F6 обновляет ресурсы; при ошибке смотрите журнал.

ModelExample.cpp

Скачать исходник
#include "ModelExample.h"
#include <Engine/Components/GameComponents.h>
#include <Engine/MainGame/BaseGameClass/Game.h>
#include <Engine/Scene/SceneAssets.h>
#include <stdexcept>

ComponentId SpawnModel(Game& game, const std::string& name,
                       const std::string& modelPath) {
    auto model = SceneAssets::CreateModel(modelPath);
    model->SetPosition({-2.0f, 0.0f, 0.0f});
    const auto added = game.GetScene().AddComponent(
        name, model, SceneAssets::ModelType);
    if (added.result != SceneResult::Ok && added.result != SceneResult::Deferred)
        throw std::runtime_error("Cannot spawn model: " + name);
    return added.id;
}

void AssignMaterial(GameComponent& object, const std::string& materialPath) {
    SceneAssets::ValidateMaterial(materialPath);
    if (!object.SetMaterialAsset(materialPath))
        throw std::runtime_error("Material unsupported");
}

void AssignTexture(GameComponent& object, const std::string& texturePath) {
    if (!object.TrySetTexture(texturePath))
        throw std::runtime_error("Cannot set texture: " + texturePath);
}

Скопируйте оба файла в Source C++ проекта. Вызовите AssignMaterial для существующего компонента с путём созданного .mat. Сборка: Build.ps1 -Runtime <папка выпуска>/Runtime. Для SpawnModel сначала импортируйте модель, используйте уникальное имя.

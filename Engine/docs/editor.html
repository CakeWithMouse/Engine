Работа редактора

Панели, управление, редактирование и запуск.

Первый сеанс

  1. Полностью распакуйте выпуск. Запустите EngineLauncher.exe, создайте проект в новой папке или откройте Project.json. Для готовых примеров C++ компилятор не нужен.
  2. Откройте редактор. В иерархии выберите объект, измените transform в инспекторе. Панели можно переносить и прикреплять, их расположение сохраняется.
  3. Меню «Вид» возвращает закрытые панели. «Вид → Сбросить раскладку окон» восстанавливает расположение. Там же доступны язык, тема и сглаживание FXAA.
  4. Выберите схему в «Правка → Схема управления»: Unreal / Unity или Blender. F фокусирует выбранный объект. Горячие клавиши зависят от схемы, поэтому ориентируйтесь на подсказки текущих инструментов.
  5. Ctrl+D дублирует объект, Ctrl+Z/Ctrl+Y отменяют и возвращают изменения. Delete в дереве удаляет выбранное. При вводе текста клавиши редактируют поле.
  6. Ctrl+S сохраняет сцену. «Запуск → Play» создаёт игровую копию, Pause приостанавливает её, Stop возвращает Edit. Изменения Play не записываются в исходную сцену.

Изменения редактора 0.3.0

Панели сцены и инспектора можно прикрепить с любой стороны. При движении gizmo инспектор сохраняет раскрытие карточек и ввод. Изменения PR №24.

Проверяемый результат

Измените позицию куба, сохраните сцену, запустите и остановите Play. После Stop исходная позиция Edit сохраняется. Закройте и снова откройте сцену: сохранённое положение должно восстановиться.

Код, HUD и восстановление

Команды C++ находятся в инструментах проекта. Ctrl+Alt+R собирает и проверяет DLL, затем восстанавливает edit-сцену. Остановите Play перед сборкой. При ошибке остаётся прежняя DLL, подробности доступны в панели «Консоль» и CodeBuild.log.

«Запуск → HUD игры…» выбирает .ui проекта. Двойной щелчок по .ui открывает визуальный редактор. «Сцена → Восстановить несохранённую сцену…» открывает восстановление. «Сцена → Экспорт игры…» создаёт отдельную поставку игры.

HUD проекта — редакция 6, движок 2026.10.31.3

Обычное подключение не требует C++
1. Скопируйте Content/UI/Hud.ui из этого примера в Content/UI своего проекта.
2. В эдиторе откройте Запуск → HUD игры…, выберите UI/Hud.ui и нажмите OK.
3. Дважды щёлкните файл в Content. В редакторе UI меняйте положение, текст,
   цвета и прозрачность; сохраняйте Ctrl+S. Холст работает без Play.
4. Запустите Play. Изменения сохранённого .ui видны во время игры.
5. Для отключения выберите «Нет» и запустите игру снова.

Кнопка «Добавить» в одной разметке не имеет действия: действие задаёт код игры.
Для выбранного HUD используйте GetProjectHud() в PreUpdate игры или BeginPlay
компонента. BindClick("add", handler) назначается один раз; SetLabelText("clicks",
text) и SetBarFill("load", value) обновляют значения по именам. Эти методы
не требуют ручной перепривязки после сохранения файла. Нужны актуальные
заголовки и Engine.lib из SDK 2026.10.31.3. Старый C++ проект пересоберите.

Опциональный пример собственного компонента на C++
TutorialHud.h/.cpp демонстрируют кнопку-счётчик и полосу прогресса.
Это альтернативный способ подключения: НЕ включайте одновременно такой
компонент и тот же HUD в настройках, иначе получите два интерфейса.

Скопируйте TutorialHud.h/.cpp в Source, Hud.ui — в Content/UI.
В ProjectGame.cpp подключите TutorialHud.h. В AfterInitialize после
Game::AfterInitialize(), до возможных ранних return, добавьте:

  AttachTutorialHud(*this, "C:/Games/Demo/Content/UI/Hud.ui");

Замените путь существующим физическим путём; для переносимой игры получите
его от каталога Content проекта. LoadMarkup сам не разрешает /Game.
BindClick хранится вне дерева. Счётчик clicks_ переживает обновление разметки,
но новый запуск игры начинает счёт заново. Старый низкоуровневый Find/OnClick
не сохраняет сырые указатели при замене дерева; для обычной логики используйте
методы по имени.

Проверка
Меняйте цвет панели и положение кнопки, сохраняйте, нажимайте кнопку в Play.
Ошибка XML оставляет прежний рабочий интерфейс. Удаление или переименование
элемента безопасно, но его имя в BindClick/SetLabelText/SetBarFill нужно согласовать
с разметкой. Атлас поддерживает ASCII и русские буквы; картинки, перенос строк,
анимации и граф событий не реализованы. Визуальный редактор сохраняет все
поддерживаемые свойства, но не комментарии и неизвестные атрибуты.

Демонстрация Battle
Сборка: .\Engine\build.ps1 -Target Battle -Configuration Release
Запуск: .\Game\build\x64\Release\Battle\Battle.exe --units 100 --static --hud
По умолчанию HUD отсутствует. F6 переключает раскраску LOD, F7 скрывает HUD.
Для проверки горячего обновления меняйте GameContent/UI/Hud.ui рядом с exe.
Постоянные изменения сохраняйте также в Game/Battle/Content/UI/Hud.ui:
сборка заново копирует исходный Content. Первая ошибка загрузки демонстрационного
HUD Battle требует исправления файла и перезапуска; выбранный HUD обычного
проекта продолжает наблюдать файл и после первой неудачной загрузки.

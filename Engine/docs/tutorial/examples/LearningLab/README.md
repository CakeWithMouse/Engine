# LearningLab: сцена, ресурсы и код

Готовый проект находится в релизе в `Tutorials/LearningLab`. Windows 10/11 x64,
Direct3D 11 и распакованный комплект достаточны для запуска. Для изменения C++
нужны Visual Studio C++ Build Tools v143 и Windows SDK. Интернет для чтения
документации и запуска готовой сборки не нужен.

1. Запустите `Open.cmd`, выберите куб в дереве, измените позицию и сохраните сцену.
   Запустите Play, затем Stop: изменения игровой копии не меняют сохранённую сцену.
2. Через «Сцена → Ресурсы → Импорт модели…» импортируйте `Docs/tutorial/resources/pyramid.obj`.
   Добавьте модель на сцену; ожидается небольшая пирамида. При повторном импорте
   используйте новый путь, который показан в контент-браузере.
3. Импортируйте `checker.png` как текстуру. Создайте материал куба, назначьте
   BaseMap, сохраните материал и сцену. Узловой вариант описан в `Docs/materials.html`.
4. Импортируйте `tutorial.wav` через «Импорт аудио…». ПКМ → «Прослушать» проверяет
   ресурс. Класс AudioTutorial запускает этот файл в BeginPlay с громкостью 0.25.
5. Выполните `Build.cmd`. Он вызывает штатный Build.ps1 с SDK из `../../Runtime`.
   Затем запустите `Run.cmd`: должны появиться вращающийся клетчатый куб,
   пирамида, HUD со счётчиком и короткий тон при наличии аудиоустройства.
6. В игровом окне R останавливает/возобновляет вращение, N добавляет куб.
   Кнопка HUD «Добавить» увеличивает счётчик. Измените 90 в RotatingCube.cpp,
   пересоберите и перезапустите игру: скорость вращения должна измениться.

Полный код находится в `Source`, ресурсы — в `Content`. ProjectGame.cpp соединяет
InputCube, ModelExample, AudioTutorial и TutorialHud. Module.cpp и автоматически
создаваемая регистрация подключают пользовательские классы к движку. В Source
также включены ReferenceExamples.cpp и ReferenceComponent.h из API Reference:
они компилируются вместе с проектом; отдельные функции не вызываются автоматически.

Модель, материал и HUD программно создаются в AfterInitialize игровой сессии.
Поэтому в режиме Edit до Play видна исходная сцена шаблона. Чтобы редактировать
объект постоянно, добавьте его через каталог сцены и сохраните сцену; не полагайтесь
на объекты, созданные только игровым кодом. PropertyTutorial показывает именно
сохранённую сцену с двумя экземплярами пользовательского класса.

Для отладки используйте логи в Binaries и штатный Hot Reload в режиме Edit.
Отладочная сборка требует соответствующего Debug SDK; комплект содержит Release SDK.
Отсутствие звукового устройства не мешает сцене работать. MP3/FLAC/OGG зависят
от доступных декодеров Windows; учебный ресурс — PCM WAV.

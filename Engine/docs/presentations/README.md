# Изменения PainEngine 0.3.0–0.4.0

Короткая презентация: 9 текстовых слайдов, без скриншотов редактора.
Включает физику Jolt из 0.3.1, Mesh, CMake/SDK, материалы, ИИ и камеру,
исправления, совместимость и результаты проверок актуальной 0.4.0.

- [PowerPoint, редактируемые слайды](PainEngine-Changes-0.3.0-0.4.0.pptx).
- [PDF для просмотра](PainEngine-Changes-0.3.0-0.4.0.pdf).

В варианте готового архива с презентациями оба файла находятся в Presentations.
Основные бинарники и SDK соответствуют проверенному комплекту 0.4.0 r3.

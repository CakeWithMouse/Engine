Работа с кодом

Создание проекта, компоненты, сборка и отладка.

C++ проект

  1. Для разработки установите Visual Studio C++ Build Tools и Windows SDK. Runtime и SDK должны относиться к одному выпуску. Для запуска готовых DLL компилятор не требуется.
  2. В лаунчере создайте проект с C++ либо добавьте C++ к существующему. CLI выполняет --create-project <новая папка> <имя>, затем --enable-code <Project.json>. Команды --create-code-project нет.
  3. Source содержит ProjectGame, Module и RotatingCube. Новые .cpp/.h в Source автоматически участвуют в сборке. ENGINE_COMPONENT регистрирует класс; сохраняйте стабильный ID при переименовании.
  4. Из папки проекта выполните ./Build.ps1 -Runtime <папка выпуска>/Runtime. В редакторе используйте Ctrl+Alt+R после Stop. Кандидат проходит проверку перед активацией.
  5. При ошибке прочитайте CodeBuild.log и validate/startup logs каталога кандидата. Game.sln удобен для редактирования и отладки, но активацию DLL выполняйте Build.ps1.

Вращающийся куб

Ниже полный минимальный вариант файлов RotatingCube. В новом C++ шаблоне одноимённый класс уже существует: замените его учебную копию или изучите её, не создавайте второе определение. Добавьте куб из каталога проекта, нажмите Play. Поворот Y увеличивается на 90 градусов в секунду.

RotatingCube.h

Скачать исходник
#pragma once
#include <Engine/Components/ComponentAnnotations.h>
#include <Engine/Components/SpecificComponents/CubeComponent.h>

ENGINE_COMPONENT("RotatingCube")
class RotatingCube : public CubeComponent
{
public:
    RotatingCube();
    void Tick(float deltaTime) override;
};

RotatingCube.cpp

Скачать исходник
#include "RotatingCube.h"
#include <cmath>

RotatingCube::RotatingCube()
{

    SetColor({1.0f, 0.65f, 0.2f, 1.0f});
}

void RotatingCube::Tick(float deltaTime)
{
    CubeComponent::Tick(deltaTime);
    auto rotation = GetRotation();
    // SetRotation uses degrees. deltaTime is scaled simulation time.
    rotation.y = std::fmod(rotation.y + 90.0f * deltaTime, 360.0f);
    SetRotation(rotation);
}

Жизненный цикл и отладка

Конструктор работает без Game и GPU. BeginPlay вызывается перед игровым вводом и Tick, Tick получает simulation deltaTime. Вызывайте непосредственную базу. Для спавна используйте Scene::AddComponent и проверяйте SceneResult. После удаления, загрузки SaveGame или hot reload прежние указатели могут быть недействительны.

Собирайте Debug с согласованным Debug SDK, подключайте Visual Studio debugger к EngineRuntime.exe и загружайте PDB своего модуля. Не смешивайте библиотеки Debug/Release. Для аппаратных проблем начните с логов и render diagnostics F7/F8.

Полные дополнительные примеры: InputCube для R/N, ModelExample для ресурсов, UI для HUD и PropertyTutorial для свойств. Они входят в комплект туториалов. В API Reference доступны полный код и объявления заголовков.

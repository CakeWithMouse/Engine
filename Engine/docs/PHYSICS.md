# Физика — 0.3.1

В Play объекты могут участвовать в симуляции Jolt. В Edit сцена не симулируется.
В инспекторе объекта откройте «Физика», включите тело и выберите его тип:
статическое (пол), динамическое (падающий предмет) или кинематическое.
Доступны box, sphere и capsule; размеры рассчитываются из мирового масштаба,
а не из треугольников импортированной модели. Настройте трение, упругость и плотность.

Для проверки создайте широкий низкий куб-пол со статическим телом и куб выше него
с динамическим телом, сохраните сцену и нажмите Play. Верхний куб должен падать
и останавливаться на полу. Stop возвращает редактируемую сцену. Изменение физики
объекта в Edit поддерживает историю Undo/Redo; в Play/Pause эта правка запрещена.

Общие настройки открываются командой «Настройки физики»: гравитация, фиксированный
шаг, максимум подшагов и число итераций решателя. По умолчанию гравитация Y = -9.81,
шаг 1/60 с, максимум 5 подшагов. Общие настройки не сериализуются в сцену автоматически;
параметры тела сохраняются в блоке `physics` объекта.

## C++ и сборка

`Game::GetSettings().Physics()` управляет настройками; `PhysicsWorld` предоставляет
создание/удаление тел, импульс, скорость и raycast. Настройки компонента доступны через
`GameComponent::SetPhysicsEnabled` и методы типов тела/формы. `RigidBodyComponent`
включает физику при создании. См. заголовки `Engine/Physics` и `PhysicsTests.cpp`.

Manifest `Engine/vcpkg.json` фиксирует зависимости Assimp и joltphysics.
При установленном Jolt сборка включает `ENGINE_ENABLE_JOLT`; без него доступна
заглушка, а симуляция не работает. Наличие карточки само по себе не подтверждает
наличие backend: проверяйте `available` расширения. Для Release нужен полный SDK
этого выпуска; C++ модули предыдущих версий следует пересобрать.

## Совместимость и границы

Формат сцены остаётся 3, Module API 5 и Edit API 6. Добавлены необязательные
расширения `Engine.Physics` и `Engine.Scene.PhysicsObject` версии 1. Старые модули
без расширений не получают эти возможности. Сцены с новым блоком `physics` не
следует открывать и сохранять старым движком; работайте с копией проекта.
Это базовые твёрдые тела и примитивные коллайдеры: mesh collision, joints, транспорт
и контроллер физического персонажа в этот выпуск не заявлены.

См. [формат сцены](SCENE-JSON.md), [Edit API](EDIT-SESSION-API.md),
[результаты проверки выпуска](RELEASE-0.3.1.md).

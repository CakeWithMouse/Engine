# Model material import fixtures

Self-authored minimal ASCII FBX 7.5 scenes: one triangle with positions, normals and UV0;
`auto-multiple` contains two meshes/materials sharing an image. Generated with Assimp 6's
exporter and completed external Texture filename fields (the exporter only populated Video).
No third-party artwork. The external one-pixel BMP is generated by AssetTests; the embedded
fixture contains the same BMP. Variants cover no texture, external, embedded, shared,
stale absolute path with `.fbm` fallback, missing image and corrupt image.

Real Blender fixtures are generated by `../make-blend-fixtures.py`: a cube with a Principled
Base Color image, with external/packed/missing variants. They are not committed and require
Blender only for the optional integration run.

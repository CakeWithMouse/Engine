# Туториал: пользовательские свойства объекта

Запустите «Открыть редактор.cmd» в этой папке. Перед вами два куба одного C++-класса RotatingCube с разными настройками.

## Попробуйте за 2 минуты

1. Выберите в дереве сцены **Медленный куб — 45 градусов в секунду**.
2. Справа сверните «Общие», «Трансформация» и «Визуал», если они мешают. Раскройте **Свойства туториала → Вращение**.
3. Измените **Скорость, °/с** с 45 на 360 и нажмите Enter. Нажмите **Play**: левый куб теперь вращается быстрее правого. **Stop** вернёт состояние редактирования.
4. Установите отрицательную скорость: направление изменится. Отключите **Вращение включено**: в следующем Play куб будет стоять.
5. В разделе **Свойства туториала → Внешний вид** измените **Яркость куба**. Это поле влияет на вид сразу, без Play.
6. **Правка → Отменить / Повторить** работают с этими полями. **Сцена → Сохранить сцену** сохранит значения для следующего открытия.

У второго куба собственные значения тех же полей. Изменение первого не меняет второй.

## Как это устроено

Откройте Source/RotatingCube.h и Source/RotatingCube.cpp:

- поля speed_, enabled_, brightness_ хранят состояние;
- SaveProjectData / LoadProjectData сохраняют его и проверяют допустимые значения;
- DescribeEditorProperties описывает названия, типы, диапазоны и вложенные разделы инспектора;
- Tick использует speed_ и enabled_ во время Play;
- LoadProjectData применяет brightness_ к цвету немедленно.

### Своё поле

Добавьте поле в заголовок, запись/чтение в оба метода сериализации и элемент в fields описания. path должен совпасть с ключом данных. Измените код, затем выполните «Проект → Перекомпилировать / Hot Reload». Изменение значения уже объявленного поля не требует сборки.

### Панель контента

Тяните широкую серую границу над «Ресурсы и код», чтобы изменить высоту. Заголовок или вкладка перемещают панель. В меню «Вид» есть компактная панель, отдельное окно и сброс расположения. Раскладка запоминается для этого проекта.

## Создание проекта из исходников примера

В репозитории выполните `./Game/PropertyTutorial/Create.ps1 -Destination "O:/Engine/Проекты/Мой туториал"`. Папка назначения должна быть новой. Нужен собранный Release runtime с SDK; можно указать его через `-Runtime`. Скрипт создаёт отдельный C++-проект, собирает и проверяет игровую DLL. Запуск готового проекта требует установленной версии из Engine.lock.json.

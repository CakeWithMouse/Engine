# Отзывы по Repair Corridor r3

- `Ai::Group`/`NavGrid` позволили реализовать маленькое тактическое управление поверх публичного API: LMB/Shift+LMB выбор, общий приказ, строй вокруг баррикады и проход после физического сдвига crate.
- NavGrid не заполняется автоматически из физической геометрии. Игровой код должен задавать статические блоки и синхронизировать динамические занятые клетки после движения физического объекта. Документация или helper для связи Jolt collider с NavGrid помогли бы уровням с подвижными препятствиями.
- Порядок инициализации важен: сетка, заданная до присоединения AI World к Play-сцене, была сброшена. Было бы полезно кратко показать рекомендуемый игровой lifecycle hook для ручного NavGrid.
- Реальные проверки выявили несколько дефектов AI: учёт члена группы как plain target (STRATEGY-007), бесконечное ожидание за полной стеной (STRATEGY-008), слишком раннее завершение отдельных бойцов, блокирующее слоты построения (STRATEGY-013), и неверное совместное использование flow-field между разными целями малых групп (STRATEGY-015). Все четыре исправлены root; после фиксов я повторил соответствующие игровые проверки. Подробные причины и regression принадлежат root issues.
- При UI hover указатель блокировался как `InputBlocked`; после двух кадров обновления cursor/hover команда по полу принималась. Это поведение нужно учитывать в scripted input последовательности и не трактовать единичный заблокированный клик как потерю команды.
- Этап проверяет один игровой эпизод, не общую матрицу. Карта процедурная, отдельной рамки выбора и расширенного редактора уровня нет. Архивный объединённый проход закончен поражением от FSM охранника, хотя маршрут всей группы был завершён без пересечений баррикады.

# Многоматериальные модели и пользовательский круг r3

Версия исходного прогона 2026.11.05.7, итоговая исправленная **2026.11.05.8**.
Windows x64 Release, MSVC v143, Assimp, Blender 5.2.
Ветка Engine/fixses. Прогон использует навыки «Опробовать движок»
и «Фикс движка после разработчиков», три GPT-6-Luna medium, четыре последовательные роли.
Круг завершён с ограничением бюджета; точные статусы — feature-matrix.csv.

## Изменение движка

Импортированные модели сохраняют исходные material IDs. В инспекторе доступны отдельные
назначения и открытие каждого .mat; SDK предоставляет GetMaterialSlots/SetMaterialSlot.
Каждая часть проходит обычный material pipeline, включая прозрачность, маску и тени.
Общий материал объекта остаётся override; очистка возвращает слоты. Назначения участвуют
в Undo/Redo, дублировании, сценах и SaveGame. Геометрия/кости и игровой объект общие:
draw calls увеличиваются по числу частей, VisibleObjects считает одну модель.

FBX/BLEND/GLB/glTF автоматически получают Base Color материалы. OBJ поддерживает ручные
слоты, без нового импортёра MTL. Полный Blender node graph/PBR и submesh-материалы для
InstancedMeshComponent не входят в реализацию. Нужна пересборка пользовательских C++ DLL
с согласованным SDK .8; старые закреплённые проекты не переключались автоматически.

## Пользовательские результаты

- [Спокойный город](calm-city/diary.md): квартал, движение машины, импорт двухматериального
  арт-объекта, слот/Undo/Redo, SaveGame в новом процессе, Pause/Resume. Есть GPU-снимки.
- [Градосимулятор](curious-city/diary.md): покупка домов экранным лучом, баланс/доход,
  HUD, SaveGame экономики/сцены; многоматериальная модель и сравнение назначения одного слота.
- [Бомбардировка](tired-bomber/diary.md): движущиеся цели, попадание бомбы, завершённые счётчики кадра/LOD,
  импортированная цель; изолированные сравнения castShadows/masked/opaque.
- [Броски хлама](ai-trash/diary.md): новый импортированный предмет наследуется от SkeletalMeshComponent,
  летит по игровой траектории, попадает в ведро. SaveGame во время полёта обнаружил BUG-R3-001.
  На .8 тот же исходный save .7 загружен в отдельном процессе: elapsed=0.5, затем hits=1.

Все четыре проекта штатно обновлены в копию и пересобраны с .8. Для спокойного города
этот прицельный повтор сделал координатор после завершения роли; остальные три повторили
сами агенты. В градосимуляторе и бомбардировке есть прямое чтение обоих слотов после Load
новым процессом. Полный второй прогон всех старых возможностей на .8 не заявляется.

Классификация каждого подозрения и ошибок — [issues.md](issues.md).
Не смешиваем дефекты Engine, ошибки игрового кода, ограничения возможностей и окружения.
Отчёты прошлых кругов и пользовательские проекты не изменялись.

## Итог покрытия и бюджет

Четыре роли прошли создание/сборку и реальный игровой фрагмент; одна новая ошибка Engine
подтверждена и исправлена (BUG-R3-001). Исходный отказ воспроизведён автоматическим тестом,
а после исправления загружен тот же .7 save в новом .8 процессе.

**67 из 85 групп** практически попробовали минимум двое, **50 из 85** имеют два успешных
результата. Ещё 17 групп имеют две попытки с частичными результатами; 18 групп попробовал
только один разработчик. Совсем непотроганных групп нет, но это не означает проверки каждого
метода и каждого визуального сценария внутри группы. Полного покрытия всех возможностей
двумя разработчиками достичь в этой порции не удалось.

Материальные слоты попробовали все четыре роли; slot-edit и slot-persist имеют минимум
по два полных успеха. Проверка UV всеми четырьмя осталась частичной; отдельный координаторский
GPU-тест проверяет все четыре угла и ориентацию. Остальные пробелы перечислены поимённо в
[coverage-gaps.md](coverage-gaps.md), исходная матрица — [feature-matrix.csv](feature-matrix.csv).

Недельный общий счётчик: **40% → 48%**, наблюдаемый прирост **8 процентных пунктов**.
Новые широкие проверки остановлены при 48%, оставив запас до пользовательского потолка 50%.
Это округлённая метрика всего аккаунта, не точный расход одного чата. Сбросы и кредиты
не использовались. Контрольные точки — [usage.json](usage.json).

Исходники всех четырёх проектов сохранены без SDK/DLL/Intermediate; ссылки и порядок продолжения —
[REBUILD.md](REBUILD.md). Все ссылки evidence проверены на существование; PNG сохранены вне build.
Тестовые процессы завершились; пользовательский launcher не закрывался. Публикация не выполнялась.

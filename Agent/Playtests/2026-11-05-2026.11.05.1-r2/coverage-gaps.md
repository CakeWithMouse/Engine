# Ограничения повторного прогона

Все 80 групп получили пробы минимум двух персон; 60 имеют два успешных
сценария, 20 остаются partial. Ниже именно границы свидетельств, а не список
отсутствующих возможностей движка и не автоматически заведённые дефекты.
Точные действия, результаты и файлы находятся в четырёх evidence.json,
сведённых в [матрицу](feature-matrix.csv).

| Группа | Что не подтверждено двумя полными сценариями |
|---|---|
| create-cpp | Оба автора собрали C++ через штатные Create→Enable; отдельный GUI checkbox создания сразу с C++ не пройден двумя авторами |
| class-wizard | Реальные проверки формы и CLI генерация есть; создание всех Game/Component/Object/Character через GUI не пройдено |
| scene-snapping | Проверен шаг вектора, но не весь UI drag/угловой snap |
| time | Изменение координат и продолжение после Load измерены; полный независимый контроль delta-time/time-scale не выполнен вторым автором |
| camera-perspective | Кадры перспективной игры есть; вся настройка камеры не проверена двумя самостоятельными опытами |
| trace-screen | Экранный луч/попадание измерены одним автором полностью; второй опыт ограничен |
| trace-debug | Hit и счётчик debug lines измерены; сама линия неразличима на одном из кадров |
| lod | Автогенерация/распределение объектов и ортографический ретест выполнены; все режимы и переходы не проверены второй персоной |
| mesh-tools | Сфера упрощена 528→264, drift 0%; полный набор операций с мешами не пройден вторым автором |
| material-params | Материал загружен и Tint/Gloss заданы; отдельное редактирование параметров второй персоной ограничено |
| material-blends | Настройки и mask path проверены; изолированного GPU-сравнения всех blend modes у двух персон нет |
| light-sun | Настройки сохранены, combined sky/sun кадр изменился; вклад одного солнца не отделён |
| shadows | Настройки и реальные тени наблюдались; отдельное on/off сравнение, range/cache двумя персонами не измерены |
| sky | Небо добавлено и отрисовано; поведение cubemap/reflection не изолировано двумя опытами |
| particle-collision | AITrash collision on/off сняты на соседних ticks; frozen sorting delta всего65 пикселей. Это не сильное доказательство причинного эффекта |
| hud-layout | UTF-8/размеры проверены; при320×240 фиксированный игровой HUD тесен, все anchors не перебраны |
| vfs | Чтение и mounts наблюдались; запись именно через VFS host API вторым автором не проверялась |
| compatibility | Закрепление версии и обновление копии проверены; старый ABI не покрыт двумя новыми опытами |
| host-services | Cursor, authoring, batch, reload и lifecycle использованы; полный набор extension callbacks не перебран |
| lod-panel | F7/F8 и target проверены через Input API, но не вручную desktop; при320×240 штатно работают многоточие/подсказка увеличить окно |

Ручное desktop UI управление не заявляется. Native EditorUiTests — настоящие
виджеты и D3D viewport под программным управлением. Qt canvas PNG не позволяет
оценить содержимое native preview swapchain. Игровые BMP получены renderer.

Подтверждённые дефекты BUG-R2-001…007 исправлены и повторно проверены.
Игровые ошибки компиляции, неверные условия самих проверок и проблемы sandbox
сохранены в журналах с причинами и исправленными повторами.

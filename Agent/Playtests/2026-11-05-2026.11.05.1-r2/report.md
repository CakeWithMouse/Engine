семь подтверждённых дефектов исправлены. Итоговый локальный SDK — 2026.11.05.5.

fix-engine-after-developers. Предыдущие исходники сохранены; проекты,
EngineStore, слоты сохранения и временные файлы изолированы в scratch.

## Исправления

1. Ортографический screen-size LOD больше не меняется только от расстояния камеры.
2. Отключённый CharacterController после Load не принимает поворот камеры.
3. project.input принимает настоящие коды кнопок мыши Engine 500/501.
4. InstancedMesh без явно назначенного материала рисует экземпляры в их позициях.
5. F7/F8 диагностики работают через общий ввод standalone и embedded viewport.
6. Обычные primitive CreateInstance корректно рисуют разнесённые копии с
   материалом и без него, включая создание после первого кадра.
7. Текстуры Mesh/InstancedMesh/FBX, заданные до подключения Game, загружаются
   при создании ресурсов. Сцена больше не требует повторного setter в игре.

Причины, исходные отказы, изображения и независимые повторы:
[журнал дефектов](issues.md), [таблица регрессий](fixes/README.md).
Ошибки игрового/тестового C++, настройки Qt и ограничения sandbox записаны
отдельно. Намеренная неудачная сборка сохранила предыдущую рабочую DLL.

## Инструменты и проверки

EngineCommandlets расширен реальными параметризованными вызовами
render.diagnostics, project.input, material.graph, project.scene.
Они используют Game/D3D/Qt/editor history и возвращают JSON с измеренными
состояниями. Повторный запуск не требует уже открытого редактора.
Контракты и зависимости описаны в Engine/docs/COMMANDLETS.md и SDK/Docs.

- RenderDiagnostics .5: 124 проверки, включая два host modes и GPU-позиции
  обычных копий; render commandlet: 10 вызовов,
  включая проверку пикселей трёх экземпляров и промежутков между ними.
- SaveGame: 78 проверок и отдельный процесс чтения; savegame commandlets: 9.
- Input/Character: 82 CPU и 101 D3D проверка.
- Базовые EngineTests: 54/54, без skipped; Asset workflow .5: 224 проверки,
  включая pending texture до attachment, SRV и реальные цветные пиксели.
- Основные commandlets: 25/25; сцена: 16 операций на двух игровых проектах.
- Material graph: Save/Revert, Undo/Redo, неверный AI JSON, блокировка записи,
  сохранность текущих правок и успешный повтор; настоящий native preview HWND.
- HUD click, удержание/отпускание и потеря фокуса, 6 действий до/после hot reload.
- Полный native EditorUiTests: 5031 проверка координатора; отдельные свежие
  пользовательские fixtures: 5028 и 5029 проверок. Числа зависят от frame pump,
  это не количество уникальных функций.
- API Reference: 39 страниц, 306 записей, 86 заголовков и 10 примеров; check PASS.

Кадры получены настоящим D3D renderer, ключевые изображения осмотрены.
Обычные UI commandlets используют Qt offscreen; material.graph и полный UI
runner — Qt windows. Снимок QWidget не захватывает native D3D swapchain превью,
поэтому по чёрной области превью в PNG не сделан вывод об ошибке рендера.
Ручное управление мышью/клавиатурой desktop не проверялось.
Восстановление после аварийного завершения проверили две персоны: свежая сцена,
7 несохранённых объектов, checkpoint, остановка процесса, загрузка всех 7
объектов новым процессом и проверка идентификатора сборки модуля.

## Покрытие и воспроизведение

Матрица содержит 80 групп: [feature-matrix.csv](feature-matrix.csv).
У каждой группы есть пробы минимум двух персон: 60 групп covered, 20 partial.
Непотроганных групп и pending нет. Полнота каждой пробы ограничена конкретными
действиями и измерениями в evidence, а не всеми возможными сочетаниями API.
Она пересчитывается из четырёх evidence.json скриптом update-matrix.ps1.
covered означает успешный проверенный сценарий у двух персон, partial —
минимум две попытки с ограничениями, pending — меньше двух попыток.
Общий тест координатора автоматически не засчитывается каждому разработчику.

Ограничения partial перечислены отдельно в [coverage-gaps.md](coverage-gaps.md).
Это, в частности, полнота GUI-мастера классов, точность визуального сравнения
теней/смешивания/частиц, узкие HUD и панели, старый ABI и запись через VFS host.
Наличие partial не означает отсутствия функции в движке. Пожелания каждой
персоны сохранены в её feedback.md; они не подменяют заведённые дефекты.

Архивы с исходниками перечислены в дневниках. Порядок восстановления без
исторических DLL: [REBUILD.md](REBUILD.md). SDK и build output в архивы не входят.
Замороженные .1/.2/.3/.4/.5 Runtime сохранены рядом в scratch; рабочий Runtime лежит
в Game/build/x64/Release/Runtime. Изменения остаются в ветке Engine/fixses;
коммит, PR и публикация в EngineStore этим запросом не выполнялись.

Потолок общего недельного счётчика — 50%; начало 28%, итоговый замер 38%.
Это общий округлённый счётчик аккаунта, не точное потребление этого чата.
История замеров: [usage.json](usage.json).

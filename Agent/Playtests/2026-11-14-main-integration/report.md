# Интеграция исправлений r6/r7 со свежим main

Пользователь явно запросил отправку всех правок в main с немедленным разрешением
конфликтов. Локальные изменения и доказательства сохранены коммитом `b8aa27c`.
Получен `origin/main` на `621986f`: PR 24 (редактор), PR 25 (физика), PR 26
(иконка и заставка) после исходного `6899a6a` прогона r7.

## Разрешение конфликтов

Два конфликтовавших файла: `Engine/Include/Engine/Runtime/GameEditModule.h` и
`Engine/Source/Runtime/GameEditModule.cpp`. Сохранены AssetImport, AI/Script/Trace
и обе новые таблицы Physics/PhysicsObject. При Reload заменяются все таблицы
вместе с владельцем DLL. Дополнительно устранено отсутствие swap PhysicsObject
в новом upstream; иначе оставались context и callbacks выгруженной DLL.

Регрессия EditorReloadTests проверяет принадлежность обеих таблиц новой сессии,
реальные вызовы read после выгрузки старой DLL, сохранение настроек тела в
checkpoint и повторный Reload. Автоматически объединённые Game/SceneEditSession
проверены на сохранение единственного тика симуляции, масштаба времени и вызова
физики внутри общего шага.

Сборка HostTests выявила ещё одну несовместимость нового upstream: позиционный
инициализатор Context в HostScriptTests передавал script в добавленное поле
physicsObject. Исправлено явным присваиванием именованных полей; HostTests
после исправления прошёл (159 проверок).

## Сборка и проверки

Проверки выполняются на Release/v143 с Assimp и Jolt, SDK предназначен для
локального использования. Результаты интеграции сохраняются отдельно от r7:
его 54 парные проверки относятся к прежнему снимку исходников, а не ко всем
новым возможностям физики и редактора.

Первая сборка остановилась в обновлении зависимостей: zlib LNK1104 при перезаписи
старого промежуточного zd.lib. Зависимости пересобраны в новом каталоге внутри
`Engine/build/main-integration-20261114`, без правок исходников зависимостей.
Логи неуспешного запуска сохранены наряду с повторными результатами.

Второй запуск остановился только на линковке открытого пользователем лаунчера.
Его exe сохранён как `EngineLauncher.before-main-20261114.exe` в локальном
build-каталоге; работающий процесс не завершался. Повторная полная сборка
All/Release/Assimp/Jolt/LocalSdk завершилась успешно, включая Katamari.

Успешные регрессии объединённого дерева:

- Engine: 83/83, без skipped; включая физику и сериализацию её настроек.
- EditSession: 682 проверки.
- Hot Reload: 65 проверок, включая обе таблицы физики.
- AI: 52/52.
- Editor Core: 1055; Host: 159; UiTests: exit 0, включая новые picker/geometry/
  inspector проверки. UiSmoke отдельно сообщает 407 проверок.
- Локальный SDK: whole-archive link v143 passed, Engine.lib SHA256
  `21183597DC9A002858D048B130D040C95A654D23B68872F74F693DF1509C7B4D`.
- Commandlets пересобраны; импорт 11/11, authoring 9/9, integer validation 13/13.
- Все четыре игровых проекта r7 пересобраны с новым SDK и запущены на 20 кадров
  (каждый exit 0). Официальный AI tutorial обновлён из нового SceneProject template
  и также запущен на 20 кадров. Сцены и архивы исходного прогона r7 не изменялись.

Точные байты доказательств r6/r7 сохраняются правилами `.gitattributes -text`,
чтобы переносы строк при checkout не нарушали сохранённые SHA256.
Также включены 14 текстовых OBJ/JSON/логов, скрытых общими build-ignore правилами;
они проверены как текст, бинарные объектные файлы не добавлялись.

Статус: интеграция и проверки завершены. Повторный fetch перед отправкой подтвердил
`origin/main=621986f`, совпадающий с объединённым upstream. Отправка выполняется
обычным fast-forward push, без force и без удаления чужих коммитов.

[Логи и коды возврата](evidence/) и [SHA256 manifest](evidence-manifest.json)
содержат результаты этого круга. Скрипты `verify.ps1` и `verify-projects.ps1`
сохраняют точные команды; для повторного запуска сценариев создания проекта
нужно выбрать новый `$out`, поскольку fixtures намеренно требуют пустой каталог.
Сохранённый [manifest SDK](sdk-manifest.json) относится к объединённому дереву.

Прежние 54 парные проверки r7 не выдаются за повторную проверку всех возможностей
добавленной физики. Здесь выполнены перечисленные регрессии и smoke игровых проектов.

# Запросы возможностей r5

Доступны прежние Physics, AI/FSM, NavGrid/Group, Input, Camera, HUD и Trace.
Новая AI-диагностика выдана по прямому запросу пользователя: кнопка AI над
viewport, восемь слоёв, выбор контроллера и пробный A→B; optional extension
Engine.Scene.AiDiagnostics v1. API read-only, вызов на scene thread, ответ
копируется во время visitor. Автоматическая проверка стандартного fixture
не заменяет пользовательский опыт на Repair Corridor.

## R5-REQ-001 — выбранная группа и смена строя

Автор предложил сравнить обход центральной баррикады для двух бойцов и понять
clearance/поле/расположение слотов. Подтверждено: Play/Pause читают активный World,
контроллер выбирается в AiSubject, selectedOnly ограничивает отображаемые группы.
Paths показывает цель группы; её обход читается по FlowField и Formation.
Маски: grid1, cost2, clearance4, paths8, field16, perception32, formation64,
probe128. Автор начинает с настоящего UI; отдельный CLI шаг пока не запрошен.

Игровой шаг — переключение линия/колонна для следующего приказа выбранной группе.
Выдан существующий Group::SetFormation; новая подсистема не нужна. Координатор
заметил возможное несовпадение AUTO radius группы с радиусами её бойцов; автор
проверяет это по фактическому поведению, без обхода через подгонку игрового radius.

## R5-REQ-002 — диагностика через project.input

Дважды завис get_window_state (в том числе screenshot-only, около 523 и 376 с).
Агент подтвердил только открытие редактора; до Play/Pause и панели AI не дошёл.
После этого выдан небольшой шаг diagnostics в существующем project.input:
request передаётся напрямую в optional API, ответ возвращается в steps[].diagnostics.

проверена отдельным native EditorUiTests --ai-diagnostics.

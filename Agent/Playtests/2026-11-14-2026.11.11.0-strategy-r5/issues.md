| STRATEGY-018 | Среда запуска / инструмент | Launcher открыл default store 2026.11.11.0, поэтому первая попытка не считается проверкой новой SDK. | STRATEGY-020 | Дефект движка | Смена строя возле барьера проецировала места слишком близко друг к другу; группа бесконечно Moving. Независимая CPU-регрессия воспроизвела без боя. Исправлено резервирование свободных мест; 58/58 AI, исходный сценарий передан автору на повтор. |
| R5-BUILD-LOCK | Локальная среда | Два оставшихся Editor-процесса r5 удерживали EngineRuntime.exe (LNK1104). Полные команды сверены с точным Project.json; закрыты только эти тестовые процессы. Повтор Runtime/SDK build прошёл. |
| R5-INVOCATION | Ошибка сценария автора | В первом точном повторе передан неподдерживаемый kind:resume вместо kind:control/action:resume. Commandlet ожидаемо вернул exit2/unknown step. Исходные файлы r5-ai-diagnostics-game-* сохранены, успешным повтором не считаются. Автор исправил запрос и запускает его под новым именем. |
| R5-FRAME-LIMIT | Ошибка сценария автора | Первая попытка продления превысила лимит кадров одного шага; commandlet отклонил bounded frame count required. Автор разбил ожидание на допустимые шаги, сохранив общий лимит2000; неуспешные файлы bounded-error сохранены. |

Диагностический запрос без controller возвращает radius по умолчанию и не выбирает
поле группы. Discovery сохранён как поиск serials, а не подтверждение AUTO radius.
Первый файл с названием column-diagnostic.bmp снят до включения overlay и является
кадром игры. Название файла не используется как доказательство визуальных слоёв.

# Находки второго этапа

База: main 388d7e9 + локальный STRATEGY-003, SDK 2026.11.11.0,
Release x64 v143. Разработчик: тот же strategy_developer.

## STRATEGY-004 — отменённый приказ показывался выполненным

Категория: user-code-error, приоритет P2. В первой реализации ручной WASD
сбрасывал `movingToOrder`, а HUD трактовал любой сброс как достижение цели.
Ожидается различие между выполнением и отменой. Исправлено автором: отдельные
состояния completed/cancelled, HUD «готово»/«отменён». Повтор того же агента:
[squad-orders-telemetry.log](strategy/squad-orders-telemetry.log) показывает
после WASD `moving=0 completed=0 cancelled=1`; боец 2 сохраняет выполненный
приказ. Координатор проверил эти данные. Статус: исправлено и перепроверено.

## STRATEGY-005 — ошибка области видимости при добавлении телеметрии

Категория: user-code-error, приоритет P2. Сборка игры остановилась на C2065
(`input` не объявлен, ProjectGame.cpp:228). Диагностика сохранена в
[command-r2-build-orders.log](strategy/command-r2-build-orders.log).
Не является дефектом SDK. Автор исправил область видимости и пересобрал модуль:
[command-r2-build-orders-fix.log](strategy/command-r2-build-orders-fix.log).
Новый код проверен реальными приказами в Play, включая новые поля телеметрии.
Статус: исправлено и перепроверено. Файл .status содержит пустой LASTEXITCODE
PowerShell-скрипта; успех подтверждён логом активации DLL и запуском её поведения,
а не выдуманным числовым кодом возврата.

## STRATEGY-006 — перехват при слишком раннем приказе

Категория: gameplay observation, не дефект движка. Сценарий с историческим именем
`order-clear-win` дал `lost=1`: охранник перехватил бойца на пути к выходу.
Автор повторил с ожиданием 55 кадров после толчка груза, без изменения FSM:
[order-clear-win-delayed-telemetry.log](strategy/order-clear-win-delayed-telemetry.log)
и [кадр](strategy/order-clear-win-delayed.bmp) подтверждают `won=1 lost=0`.
Оба результата сохранены; первое имя файла не считается доказательством победы.

Ограничения игры: движение к точке прямолинейное, поиска пути и физического
обхода препятствий нет. Закрытый груз блокирует пересечение линии по игровому
правилу; движение симуляции после терминального результата не замораживается.

Подтверждённых новых дефектов Engine на этом этапе пока нет. STRATEGY-003
с прошлого этапа остаётся локальным исправлением обязательной SDK-базы.

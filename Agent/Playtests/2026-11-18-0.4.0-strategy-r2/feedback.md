# Feedback — Mesh Physics 0.4.0

- **Mesh-shape contract should be explicit in public docs.** Before the release documentation update, `SCENE-JSON.md` and `EDIT-SESSION-API.md` listed only box/sphere/capsule despite public `PhysicsShapeType::Mesh` / PhysicsObject shape value 3. The release coordinator updated the shared docs. The gameplay distinction is consequential: static Mesh retains the concave aperture; a moving mesh is represented by a convex hull, so an open tray behaves as a filled collision hull.
- **Build-tree Runtime and packaged Runtime differ.** The raw CMake build-tree Runtime does not include `GameExecutable.exe` (and does not include EngineCommandlets.exe). Direct `Export-Project.ps1` against it returned the documented missing-export-support LaunchError. The packaged CMake Runtime plus MSBuild wrapper passed external package export checks; these should not be confused with a raw build-tree export pass.
- **Transform correctness matters to real gameplay.** A centered opening with asymmetric piers plus negative X scale made the mirror-transform regression observable without changing the old corridor route. The runtime crate crossed the opening and moved from z=2 to z≈5.52. Keep test fixtures asymmetric; symmetric geometry could hide a lost mirror transform.
- **A physics probe needs a created body before initial velocity is assigned.** `SetPhysicsLinearVelocity` before the component's first `SyncPhysicsBody` silently has no effect. The game now waits for `HasPhysicsBody()` in its first component tick and applies velocity once. A body-creation callback or documented lifecycle would make this sequence easier to discover.
- **Persistence and simulation are separate claims.** The native Edit API host proved imported model asset and Mesh physics state survive destroy/create/load in a new session. It did not simulate the reopened imported mesh. A small documented scene API fixture or commandlet action could let projects verify collision after reopen without creating a private host.
- **The Inspector visual check remained incomplete.** The one Editor launch yielded no targetable window and no redirected exit/log. Native Mesh combo tests passed with coordinator provenance, but they do not replace a visible project-level inspector check.

# Прогон r7 — 2026.11.11.0

Статус: завершён. Все **54 целевых пункта** — 48 прежних partial и шесть новых
AI-пунктов — получили минимум два **passed от разных агентов** на версии
2026.11.11.0. Остаток равен нулю. В общей матрице **113/113** имеют по два passed:
59 исходных строк сохраняют явно отмеченные исторические доказательства r6.
Числа и доказательства находятся в [coverage.json](coverage.json) и
[feature-matrix.csv](feature-matrix.csv). Частичные проверки и чтение исходников
не засчитывались вместо успешного выполнения критерия.

Все шесть новых AI-пунктов получили по два независимых passed: карточка/память,
реальные диалоги графа, validation/отказ Play, runtime debug, двусторонняя связь
со скриптом и save/retry/reload. Все 48 legacy-критериев также закрыты.
Сохранены 129 наблюдений ролей: 122 passed и семь partial любознательного автора;
для каждой из этих семи фич есть два passed других независимых агентов.

## Версия и сохранность работы

После fetch на origin отсутствовала ветка develop. Новая разработка с AI-редактором
влита в main: d74aebb → 6899a6a (PR 23), версия 2026.11.07.6 → 2026.11.11.0.

локальные исправления r6 перенесены. Исходные проекты предыдущих прогонов сохранены,
коммиты и публикация релиза не выполнялись.

На машине нет MSVC v142, который новый релиз требует для распространяемого SDK.

[Manifest текущего SDK](coordinator/sdk-manifest.json) содержит SHA256 Engine.lib.

## Что проверено координатором

Полная сборка Engine/Editor/Runtime/SDK прошла после исправления начального
пространственного звука и масштаба времени Editor Play. Подходящие регрессии:
Engine 81/81, AI 52/52, EditSession 682 (включая новую регрессию времени),
Editor Core 957, Host/Ui, native EditorUi 7170, HotReload 57,
импорт commandlet 11/11, authoring 9/9, integer validation 13/13.
Эти результаты не засчитываются автоматически как проверки игровых персон.

AI-диагностика использует настоящие Qt-окна редактора, диалоги состояния и перехода,
карточку персонажа и runtime-сессию. Нативная диагностика сцены дополнительно
проверяет клики в viewport и hierarchy, Ctrl-выделение, Focus и поля Transform.
В диагностике v9 проверены также настоящий mouse drag с Undo, переключение
World/Local и согласованность projection aspect с фактическим viewport после
двух resize. [Проверка записанного сценария](coordinator/check-editor-v9.py)
читает сохранённый результат; это дополнительное доказательство координатора.
Qt-снимок виджетов не захватывает поверхность D3D; чёрная область viewport в таком
снимке не используется как доказательство правильного игрового изображения.
Диагностика v10 проверила правую кнопку мыши для поворота камеры без изменения
объектов. Для material preview основной viewport временно минимизируется:
сохранён настоящий D3D-кадр preview 389×282, размер совпадает с его HWND.
Это устраняет ошибочную запись основной сцены вместо preview; общее успешное
сохранение материала само по себе не подтверждает картинку preview.
В v11 проверены настоящие toolbar/Inspector UI-редактора (Label/Button,
кириллица, anchor/rect, выбор в иерархии, Save и повторное открытие) и
OK/Cancel/None в диалоге HUD. Сценарий и assertions сохранены в
[check-editor-v11.py](coordinator/check-editor-v11.py); игровой эффект HUD
по-прежнему проверяется отдельными ролями в Runtime.
В v12 `project.input` меняет реальный viewport через EditorQtHost и поддерживает
cursor в новом размере. Кадры Play 1280×720 → 640×480 и соответствующие матрицы
проверены в [check-editor-v12.py](coordinator/check-editor-v12.py); в кадре видны
сохранённые UI-элементы. SDK при изменениях диагностической обвязки не менялся.

Реальное аудио проверено двумя ролями через WASAPI loopback с различными
тестовыми сигналами. Измеряется выход звукового устройства; прослушивание человеком
не заявляется. Для 3D учитывается реальная позиция listener, следующего за Player.

Пять подтверждённых ошибок исправлены и независимо перепроверены:

1. Устаревшие AI/Script/GraphTrace/PointLight таблицы после Hot Reload.
2. AI test runner требовал отсутствующий исходник руководства.
3. Повреждённые явные import options подменялись defaults.
4. Play3D запускал источник до пространственного расчёта, вызывая начальный звук
   без затухания до первого Update.
5. Editor Play игнорировал Game time scale. Regression fail-before/pass-after и
   два независимых повтора подтвердили масштаб времени и перемещения, Pause/Resume.

Минимальные воспроизведения, причины и повторы описаны в [issues.md](issues.md).
[Независимый статический обзор](coordinator/code-review.md) пяти исправлений r7
не выявил новых замечаний; он отделён от исполняемых проверок и не расширяет
заявленный охват на весь репозиторий.
Небольшие исходные логи, JSON-запросы/результаты и снимки координатора сохранены в
[coordinator/evidence](coordinator/evidence); [manifest](coordinator/evidence-manifest.json)
позволяет сверить их SHA256. Ошибочные промежуточные запуски сохранены для аудита,
их коды возврата не подменяются успешными повторениями.

## Границы проверки

Полный охват всех путей кода или повтор всех 113 фич на новой версии не заявляется.
На новой версии два независимых агента проверили именно 54 целевых пункта;
`remainingTargetRows` пуст. Исторические результаты отделены в матрице.
Нереализованное marquee-выделение не включается в критерий работающего click/Ctrl
selection. Дополнительная AI-сцена четвёртой роли имеет функциональные доказательства
состояния/памяти/перемещения, но её собственный D3D-кадр не подтверждён; это явно
помечено в evidence и не заменяет основные парные проверки AI. Измеренное аудио
не является субъективной оценкой звука, а сценарии прозрачности не доказывают
произвольные самопересечения внутри одного mesh.

Общий округлённый счётчик аккаунта отслеживается в [usage.json](usage.json),
исходное значение всего продолжающегося круга — 7%, начало фазы r7 — 20%.
Итоговое значение — 41%: +34 процентных пункта за весь продолжающийся круг,
из них +21 за фазу r7. Счётчик не измеряет точное потребление отдельного чата.
При значении 29% пользователь явно выбрал «Продолжать до полного покрытия» и снял
прежнее ограничение бюджета навыка. Базовая метрика сохранена, расход не обнулён.

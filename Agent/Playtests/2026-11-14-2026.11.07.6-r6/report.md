## Версии и исходное состояние

Четыре сохранённых проекта r5 закреплены на **2026.11.07.0**. Имя каталога
предыдущего прогона содержит 2026.11.06.1 — это его стартовая версия, а не версия
финальных проектов. Текущий main — **d74aebbc**, версия **2026.11.07.6**:
релиз a7f8c8d плюс последующий PR #21 с настройками масштаба импорта.
Контракты: sceneFormat 3, moduleApi 5, editApi 6 с поддержкой 4/5/6.

Все четыре проекта обновлены в отдельных копиях и пересобраны с текущим SDK
и исправлениями r6. Старые проекты сохранены. Номер версии не повышен;
это локальная исправленная сборка, не опубликованный релиз. При повторении
нужно явно указывать Runtime из Game/build/x64/Release/Runtime: частное
хранилище EngineStore с тем же номером .6 может содержать прежнюю сборку.
[Сравнение lock, модулей и исходников](project-comparison.json),
[хеши Runtime/SDK и проверка архивов](artifact-verification.json).

## Исправления и рефакторинг

Закрыты три воспроизводимых дефекта, с доказательствами до и после:

1. **BUG-R6-001:** допустимое имя Hero..v2 отклонялось как выход в родительский
   каталог. Теперь проверяется сегмент пути, настоящий `..` остаётся запрещён.
2. **BUG-R6-002:** неверный scale мог пройти обработку команды импорта. Добавлена
   ранняя проверка типа, конечности и диапазона до изменения проекта.
3. **BUG-R6-003:** Play сообщал игровому коду, что симуляция выключена. Исправлены
   состояния Play/Pause/Resume и ошибки тика; рендер после явного шага больше
   не запускает второй Tick. Прежний одноаргументный вызов API сохранён.

Добавлен commandlet project.import для настоящего импорта, размещения,
переимпорта и переноса. Удалена тестовая имитация записи sidecar из HostTests,
вместо неё добавлена проверка реального файлового потока. Обновлены справка,
контракты импорта и сгенерированный API Reference.
[Дефекты](issues.md), [итог исправлений](fixes/report.md),
[области проверки кода](code-review.md), [анализ дальнейших улучшений](improvement-analysis.md).

## Проверки и границы результата

Полная Release All сборка с Assimp прошла. Итоговые связанные регрессии:
EngineTests 70/70; EditSession 670 проверок; SaveGame 103 и отдельный процесс;
assets 229; ABI fixtures 116; Core 478; Host 83; import dialog 25;
import e2e 9 сценариев. Native Qt: standard 4872, authoring 215, layout 236,
reload 350, workflow/recovery; HUD/reload по 50. Viewport проверил реальные
пиксели, анимацию, resize/minimize/reattach. API Reference --check прошёл.

Широкая GPU-матрица: **202 сценария, 1920 кадров** материалов, point shadows,
прозрачности и пересечений. Она выполнена до исправления Play; после него
повторены связанные регрессии и собственные GPU-сценарии ролей. Ошибки запуска
material-graph исправлены и повтор прошёл; история сохранена в retries.json.
Не следует читать первоначальный regressions.json как итог без этих повторов.

[Матрица возможностей](feature-matrix.csv) сохраняет все 95 прежних пунктов и
добавляет 12 уточнений нового функционала. Старые успешные результаты не
перенесены автоматически. **54 из 107** пунктов попробовали минимум две роли;
**14** имеют минимум два passed. Остальные 53 пункта не достигли двух попыток.
[Исходный coverage.json](continuation/coverage-before.json) содержит точные списки; partial означает
конкретный проверенный сценарий, а не весь раздел.
Пресеты/Cancel диалога и крайние случаи register/чисел материалов проверены
координатором, но не двумя независимыми игровыми ролями. Не все исторические
возможности повторены двумя авторами в этом круге.

Проверка кода включала полную сборку и широкие регрессии с прицельным чтением
изменённых подсистем; это не построчный аудит всего репозитория. Прямой осмотр
всех четырёх окон Edit/Game и пикселей material preview не подтверждён:
computer-use вернул `Computer Use app approval timed out`. Автоматические
Qt/GPU-проверки и просмотр сохранённых игровых кадров учтены отдельно.

## Локальное состояние

Удалён пустой случайный каталог E:/Engine/.exe. Сбой MSVC C1902 в sandbox обойдён
обычной сборкой на host без изменения системных настроек. Конкурирующее чтение
SDK при его экспорте устранено последовательностью сборок; целостность SDK
проверена хешем. Служебные окна и процессы координатора закрыты. Прежние
пользовательские изменения r5, старые проекты и полезные сборочные данные
сохранены. Подробности спорного локального lock-файла есть в отчёте curious-city:
его наличие само по себе не доказывает блокировку сборки.

Общий недельный счётчик аккаунта изменился с **7% до 12%** (+5 процентных
пунктов при бюджете 30); это наблюдение общего лимита, не точный расход чата.
[Замеры](usage.json). Изменения остаются локальными: коммит, новая версия и
публикация не выполнялись.

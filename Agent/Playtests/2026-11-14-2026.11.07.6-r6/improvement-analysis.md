# Следующие улучшения по четырём ролям

Исходные отзывы r6 сохранены. BUG-R6-001/002/003 уже исправлены, поэтому ниже
они не выдаются за будущие возможности. Приоритеты — порядок небольших итераций,
не обещание сроков. Аналитические выводы отдельно отмечены.

|---|---|---|---|---|
| [Спокойный город](calm-city/feedback.md) | CPU/код подтверждает tangent basis, но отражённый normal-map материал не был осмотрен автором в редакторе | Небольшая образцовая сцена с обычным/зеркальным масштабом, фиксированным светом и объяснением ожидаемой нормали | P2: два кадра A/B и понятный пример из SDK | Вывод аналитика из явно непроверенной задачи автора |
| [Градосимулятор](curious-city/feedback.md) | Цикл строительства стал понятнее после русских подписей и подсказки клика по земле; нет desktop кадра HUD | Закрепить этот игровой пример и провести визуальный Edit/Game resize при доступном desktop | P2: цена/баланс/Save/Load читаются при двух размерах, покупка и загрузка видны | Практическое улучшение автора + вывод аналитика о проверке |

Общее: параметризованные команды полезны для воспроизводимости, но снимок Qt
не включает D3D swapchain. Следующая небольшая итерация — доступный визуальный
прогон четырёх сохранённых проектов, особенно material preview и game HUD.
Не следует добавлять новую систему физики или переписывать рендер ради этих
отзывов. Реальные CLI import/spawn и разделение render/step уже добавлены в r6.

Порядок: (1) сохранить три регрессии в обычном цикле проверок, (2) закрыть прямой
визуальный прогон, (3) откалибровать игровой пример бросков, (4) улучшить пример
normal map. Проверки пресетов/Cancel и новых ошибок .mat уже есть у координатора,
но в матрице не приписаны двум игровым авторам без их отдельных опытов.

## Обновление после продолжения

Прежние рекомендации выше описывают первый этап. Продолжение уже добавило
наблюдаемые GPU-сценарии normal map с отражением/SaveGame, частицы с A/B контактом,
реальные формы генератора классов и scale presets/Cancel, startup/recovery,
а также границы графа материалов. Выявленные normal-map, empty-schema, texture
register overflow и Sky cubemap дефекты исправлены и повторены ролями.
См. [новый отчёт](continuation/report.md) и [его регрессии](continuation/regressions.json).

Оставшиеся улучшения по фактическим ограничениям: прямой desktop Edit/Game прогон
и прослушивание 2D/3D/stream с проверкой затухания. Они не заменяются API acceptance.
Для повседневной разработки полезно сохранять новые проверки в обычном
регрессионном цикле; дополнительных крупных систем этот прогон не требует.

# Итог исправлений r6

Три подтверждённых дефекта воспроизведены и исправлены. Передфиксные доказательства
сохранены: `logs/core-before.log`, `logs/ui-before.log`, `logs/simulation-before.log`
и сценарий автора бомбардировки. Подробные контракты — [issues](../issues.md).

1. Имя `Hero..v2` больше не отклоняется как родительский путь; настоящий сегмент
   `..` всё ещё запрещён.
2. Некорректный масштаб команды импорта отвергается до изменения проекта:
   строки без числа, boolean, ноль, отрицательные, overflow, NaN/Infinity.
3. Play/Resume сообщают пользовательскому Game включённую симуляцию, Pause и
   ошибка тика — выключенную. Отдельный параметр viewport-рендера исключает
   повторный автоматический Tick. Одноаргументный публичный вызов сохранён.

Добавлен `project.import` поверх настоящих Assets.Import/CommandFinished/UseAsset.
Он проверяет sidecar, размещение, переимпорт, перенос и трансформации объектов.
HostTests больше не записывает ожидаемый JSON вместо производственного кода;
файловый контракт проверяет новый e2e runner. Документация и HTML API обновлены.

## Локальные проблемы и ограничения

MSVC C1902 в sandbox устранён для прогона обычным host-запуском; установленная
среда и системные настройки не менялись. Первый full-editor runner попытался
повторно переименовать SDK, пока его читали игровые сборки. Атомарный exporter
сохранил прежний полный SDK; его Engine.lib совпал с текущей библиотекой по SHA256.
Повтор выполнен с целевыми свежими сборками тестов и `-SkipBuild`, без замены SDK.
Сбой material-graph был ошибкой параметра/fixture координатора, исправленный
повтор прошёл; оба события сохранены и не объявлены багами движка.

Прямой computer-use осмотр окна остановился на `Computer Use app approval timed out`.
Созданные координатором процессы закрыты. Это не отменяет Qt/GPU проверок, но
прямое наблюдение всех четырёх редакторных окон и preview pixels не подтверждено.
Пустой случайный каталог E:/Engine/.exe удалён; старые проекты и исходные изменения
r5 не тронуты. Коммит, выпуск нового номера и публикация не выполнялись.

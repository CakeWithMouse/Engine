# Прогон r6

Исходник d74aebb, Engine 2026.11.07.6; после релизного a7f8c8d в main добавлены настройки импорта (PR #21). Бинарники перед опытом пересобираются. Предыдущие четыре проекта r5 требуют 2026.11.07.0; Scene 3, Module API 5, Edit API 6 сохранены, C++ пересобирается с текущим SDK.

Три агента GPT-6-Luna medium: calm-city, curious-city, tired-bomber. Четвёртая роль ai-trash — отдельное followup первому. Запись движка и общие сборки выполняет координатор; каждому выделен свой проект и отчёт. Desktop/GPU сценарии согласуются последовательно.

Фазы: сравнение старых архивов и отзывов → свежая сборка и регрессии → чистое создание и обновление копий проектов → собственные игровые опыты новых функций → воспроизведение дефектов и минимальные исправления → повтор сценариев, исходные архивы и матрица покрытия.

Новое после r5: каскады при движении камеры; animated point shadows, две лампы/слоты/LOD; material graph/HLSL и устойчивость загрузки; прозрачные слои/LOD и пересечения; настройки масштаба импорта/sidecar/spawn. Каждой новой функции назначаются минимум два разных разработчика. Старые 95 пунктов каталога также учитываются без переноса старых passed в новый прогон.

Исходные локальные изменения сохранены: r5/curious-city/evidence/fresh-enable.stderr.log (изменён), create-enable.json и fresh-enable.exitcode.txt (неотслеживаемые). Не удалять исторические проекты, пользовательский EngineStore и чужие приложения.

Публикация релиза и коммит не входят в этот круг. Полноту проверки кода и визуального поведения нельзя выводить только из компиляции; ограничения фиксируются отдельно.

# Ревью импорта настроек модели — до READY

## Подтверждённый дефект пути (по чтению кода; не runtime-проверка)

`Editor/Core/ModelImportSidecar.cpp`, `ResolveSidecarPath`: абсолютный `/Game/...` и относительный путь отвергаются, если строка содержит подстроку `..`, до нормализации пути. Поэтому легальный файл `Content/Models/Hero..v2.glb` не может получить/прочитать sidecar: `WriteSidecar` возвращает false с сообщением `outside project sandbox`, а `ReadSpawnScale` сообщает Error и вернёт 1.0. Это воспроизводимый false positive для имени файла с двойной точкой, не обход sandbox. Решение — проверять компоненты `..` после нормализации/сравнения корней, как уже отмечено открытым пунктом `Editor/PLAN.md` (путь-компонент вместо `contains`). Не исправляю Engine в рамках роли.

## Риски, требующие проверки/уточнения

- Та же функция сравнивает префикс `cleanAssetPath` с `cleanProjectRoot` через `Qt::CaseInsensitive`. На Windows это привычно, но на регистрозависимых файловых системах может признать путь с отличающимся регистром вложенным. Не подтвердил практическую эксплуатацию; проверить платформенный контракт/канонизацию прежде чем регистрировать дефект.
- `ImportSettingsDialog` задаёт `QDoubleSpinBox::decimals(4)`, хотя core принимает `float` до 1e4. Пользовательский ввод с более чем четырьмя дробными разрядами округлится. Вероятное ограничение точности; проверить, нужно ли это для рабочего масштаба.
- `ImportSettingsFile::Parse` пишет default в output до валидации и корректно отдаёт false/Error; верхний слой `ReadSpawnScale` возвращает 1.0. Для отсутствующего sidecar отдельно штатный NotFound/Info. Это предусмотренная деградация, не дефект.
- В импорте модели одна настройка масштаба на выбранный пакет, далее она записывается в sidecar отдельно для каждого успешно импортированного `/Game/...` ассета. Нужно проверить реальное поведение при частичном отказе импорта и отмене диалога.
- В `MainWindow.cpp` обработка успешного импорта проверяет `command.path.startsWith("/Game/")` с чувствительным к регистру сравнением, тогда как helper sidecar распознаёт `/Game/` без учёта регистра. Потенциальная несогласованность, если importer/API может вернуть `/game/...`; ожидаемый путь штатного host пока не установлен.

## Проектный workflow

`Engine/docs/RELIABLE-WORKFLOW.md` предписывает запуск старого проекта обычной кнопкой Play/Edit и выбор между обновлением копии, прежним runtime и отменой; исходная папка сохраняется. Для явного CLI-регресса из прошлого опыта сначала нужен build custom DLL на pinned SDK, иначе migration loader не знает пользовательский компонент. Версия 2026.11.07.6 добавляет обработку прозрачных пересечений; проектные C++ DLL пересобрать новым SDK. Код импорт-настроек и шаблонные тесты изучены read-only, тесты/сборки не запускались.

# Готовая поставка PainEngine 0.4.0

18.11.2026. Архив: `Engine/build/releases/PainEngine-0.4.0-win64.zip`.
Размер: 148081100 байт. SHA256:
`414c448257100cc84692018aee90625f22f5bb11478a76fe2677179edcd31096`.
Рядом находятся `.sha256` и `.validation.json`.

Упаковщик и актуальная документация: коммит `32b25fce` ветки release/v0.4.0.
Runtime и основной SDK собраны CMake/Ninja, MSVC 19.40; Qt 6.7.2, Assimp и Jolt.
GameExecutable.exe и EngineCommandlets.exe взяты из проверенной MSBuild-сборки
того же кода 0.4.0. C++-проект получателя собран MSVC 19.44 через CMake SDK.

## Состав

Launcher, Runtime, Editor, командлеты, CMake SDK, необходимые Qt/OpenSSL/CRT DLL,
пять отдельных игр, RuntimeExample, AiTutorial и RepairCorridor с исходниками.
Обновлены офлайн HTML/Markdown, сведения о составе комплекта и статус редактора ИИ.
Включены лицензии, source archive стратегии, журналы проверки и файловые хеши.
Исторические презентации, старые runtime, PDB и каталоги сборки не включены.

## Проверки

- Актуальная Release-сборка: CTest3/3, включая EngineTests.
- Готовая папка: 24/24. Шесть примеров, пять редакторских режимов, оба учебных
  проекта, новый проект, C++ Enable/build/startup, экспорт/Game.exe и командлет Play.
- Изолированный PATH не содержит DLL из рабочего checkout. Проверен внешний
  CMake SDK из перемещённой поставки, включая новый Unicode-проект.
- Файловая проверка: 15 HTML, 126 локальных ссылок, 182 PE x64; нет пропущенных
  локальных ссылок и ненайденных DLL.
- ZIP CRC: PASS. После новой распаковки совпали все 1425 SHA256.
- Из распаковки: 19/19 дополнительных запусков игр, редактора и новых проектов.

`VALIDATION.json` относится к полной проверке папки; `extracted-VALIDATION.json`
— к повтору из ZIP. Все подробные логи полной проверки также находятся внутри
самого архива, в `Validation`.

## Найденное при сборке поставки

Первый фильтр исключал .obj как объектные файлы, затронув модели Katamari.
Фильтр исправлен, все игры повторены. В поставку добавлены OpenSSL 3.0.14 DLL
из того же Qt kit и qoffscreen.dll: последний требуется командлетам и не
добавлялся обычным windeployqt. После исправлений проверки прошли полностью.
Неудачные промежуточные staging/логи сохранены в игнорируемом build-каталоге.

Непосредственные UI-взаимодействия прежнего игрового агента оставались partial;
новый пакет проверен штатными автоматическими сценариями. Linux/macOS/clang-cl
для этого архива не проверялись. Исторические результаты не засчитаны как новые.

## Публикация

Первая попытка `git push -u origin release/v0.4.0` не была выполнена:
автоматическая проверка отклонила публикацию, поскольку не был подтверждён
доверенный статус назначения `https://github.com/CakeWithMouse/Engine.git`.
Запрошено явное подтверждение пользователя. Отказ не обходился; архив подготовлен локально.

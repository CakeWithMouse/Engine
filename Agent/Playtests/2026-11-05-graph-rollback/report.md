# Откат графа при ошибке файловой системы

Дефект из PR #16: `RestoreGraphFiles` сбрасывал резервную копию до записи и игнорировал
результаты записи, commit и удаления. «Откатить» продолжал перечитывание состояния, а
«Не сохранять» закрывал окно даже при невозможности вернуть исходные файлы.

Исправление: проверяются открытие, полный размер записи, commit и удаление нового графа.
Резерв сбрасывается только после успешного восстановления обоих файлов. При ошибке
показываются путь и причина; окно и резерв остаются доступны. Ошибка из `Shutdown`
передаётся в `CloseMaterialEditors`, поэтому закрытие главного редактора также прекращается.
Частичное восстановление допускается: повторная попытка использует обе исходные копии.
Аварийное завершение процесса по-прежнему не сохраняет резерв на диск.

Регрессионные сценарии в `Editor/tests/EditorUiTests.cpp` используют настоящий Windows handle
без `FILE_SHARE_DELETE`, блокирующий замену/удаление файла:

1. Ошибка commit HLSL при «Откатить»: окно, изменённый граф и dirty-флаг сохраняются;
   после снятия блокировки оба файла восстанавливаются.
2. Ошибка commit JSON после восстановления HLSL при закрытии главного редактора:
   закрытие отменяется; повторное закрытие окна материала восстанавливает оба файла.
3. Ошибка удаления графа, созданного поверх кодового материала: окно не закрывается;
   после снятия блокировки новый граф удаляется, исходный HLSL восстанавливается.

Проверено 2026-11-05: Release-сборка с Assimp и полный `Editor/tests/run.ps1
-Configuration Release -EnableAssimp` — 5028 проверок UI прошли, включая все три
сценария отказа и повторного отката. CoreTests: 374 проверки прошли.
`git diff --check`: без ошибок.

Промежуточные ошибки разработки теста (устранены):

- C2248/C2664: первоначальное обращение к private `CloseMaterialEditors`; заменено
  реальным публичным действием `QWidget::close()` главного окна.
- Сравнение пути в диагностике учитывало разные разделители `/` и `\` как различие;
  нормализованы разделители, сохранена проверка полного пути и типа предупреждения.

Логи сборок и прогонов находятся в игнорируемой папке `Engine/build/graph-rollback-*`.

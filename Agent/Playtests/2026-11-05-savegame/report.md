# SaveGame — реализация и проверка

2026-11-05, Engine/fixses, версия сборки 2026.11.05.0. Engine не содержит правил игр:
снимок сцены + SerializeSaveGame базовых классов + поля наследников. Пользователь явно
попросил повторный прогон только первого разработчика, поэтому запущен один агент
`calm_city_savegame`, GPT-6-Luna / medium, в отдельной копии Calm City.

## Проверки координатора

- `Engine/tests/savegame/run.ps1`: 73 проверки; отдельный процесс читает ранее созданный
  слот. Включены Scene/иерархия/transform, поля Game/Component/Subsystem, ссылки с remap,
  базовые классы, Unicode/UI/mesh, неверные данные, сохранность мира при отказе, lock файла,
  Deferred, Busy, Stop, поток-владелец, настоящий D3D viewport, cold load камеры/HUD,
  отложенные уведомления cold load, Stop из post-load callback, числовое переполнение,
  продолжение Tick после загрузки и неизменность edit-сцены после Stop.
- `Editor/tests/SaveGameCommandletTests.ps1 -SkipBuild`: 9 вызовов, настоящие Store и
  сериализация встроенных классов; каждый вызов отдельным процессом, включая отказ записи.
- `Engine/tests/subsystems/run.ps1`: lifecycle и headless/viewport тесты прошли.
- `Engine/tests/scene-module/run.ps1`: 109 проверок прошли.
- `Engine/tests/edit-session/run.ps1`: 651 проверка прошла. Fixture RuntimeExample сообщает
  об отсутствующей CesiumMan.glb; это сообщение существующего fixture, не успех импорта.
- `Engine/tests/savegame/SdkPublishTests.ps1`: блокировка SDK не меняет старые файлы,
  повторное обновление публикует согласованные headers/lib.
- API Reference: 39 страниц, 302 entries, проверка актуальности прошла.
- HTML-схема: четыре переключаемых сценария проверены исполнением JavaScript с DOM stub;
  это функциональная проверка, не визуальная проверка браузера.
- Финальная сборка Launcher/Runtime/SDK прошла; SHA256 Engine.lib в SDK совпадает
  с библиотекой движка, на которой прошли тесты.

Логи: `Engine/build/savegame-*.log`; fixtures остаются в Engine/build, не в библиотеке
проектов пользователя. Отчёт Calm City обновляется отдельно в `calm-city/`.
Копии основных результатов сохранены рядом: `savegame-tests.log`, `commandlet-tests.log`,
`fixes/sdk-publication.log`.

## Промежуточные ошибки разработки

- Test factory PointLight не имел конструктора без аргументов: исправлена фабрика теста.
- Commandlet: переменная `slots` конфликтовала с макросом Qt; переименована.
- Viewport-тест передал dt > 0.1 и null visitor, нарушая существующий контракт; исправлены
  входные значения теста, контракт движка не ослаблялся.
- LNK1101/MSPDB140 у агента: sandbox/toolchain, повторная сборка в штатном MSVC окружении.
- CUA: системное разрешение доступа к приложению не получено (timeout); ручная GUI-проверка
  не заявляется выполненной. Проверки проектной DLL/выгрузка кадров учитываются отдельно.

## Бюджет и границы

Счётчик аккаунта перед фазой 21%, после проверок 25% недельного окна; общий с другими чатами,
не точный расход этой задачи. Ни сброс лимита, ни покупка кредитов не выполнялись.
GPU-буферы/подписки воссоздаются; snapshot не копирует изменённые ассеты `.mat` и не сохраняет
содержимое GPU particle/animation/cubemap буферов. Подробный контракт в Engine/docs/SAVEGAME.md.

## Итог первого разработчика

Calm City реализует SerializeSaveGame в CarMover: базовые поля получает от CubeComponent,
свои speed/moving/goingRight записывает в версионируемую секцию. Игровая логика остаётся
в проектной DLL. Сохранение — F6, загрузка — F9; F5 оставлен штатному переключению рендера.
Ручное нажатие клавиш через GUI не проверено; вызовы того же API проверены автоматически.

Два процесса Runtime завершились с exit 0. Первый: сохранение X=5.6 с направлением влево,
продвижение до X=3.1, загрузка X=5.6, продолжение до X=5.35. Второй процесс прочитал тот же
слот и подтвердил X=5.6 → 5.35. Это проверка полей наследника и базового transform.
Детерминированный режим останавливает автоматический ход времени и вызывает Tick явно;
обычный режим игры работает с timeScale=1. Движение через обычный update после загрузки
дополнительно проверено в SaveGameTests с D3D viewport.

Осмотрены реальные BMP-кадры после загрузки в обоих процессах: город, машинки, свет и тени
присутствуют, оба файла имеют SHA256 `F1A8B3775346D0B9DA24D36F39A43A325B798E39923C0361EFC25EBDDBC4DB7F`.
Первое подозрение на чёрный кадр не подтвердилось: tool preview получил BMP с MIME
application/octet-stream; повторный показ с image/bmp отобразил город. Файлы не изменялись.

Два подтверждённых дефекта поставки исправлены навыком «Фикс движка после разработчиков»,
см. [отчёт исправлений](fixes/report.md). После повторного прогона новых воспроизводимых
дефектов SaveGame не обнаружено. [Дневник и артефакты агента](calm-city/diary.md).

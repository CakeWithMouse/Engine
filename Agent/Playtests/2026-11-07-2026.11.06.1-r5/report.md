# Повторный прогон новых правок: r5

Исходник 55d3b0c, версия 2026.11.06.1. Итоговая сборка **2026.11.07.0**, Windows x64
Release / MSVC v143, Qt 6.7, Assimp. Исходное рабочее дерево было чистым.
Три GPT-6-Luna medium, четыре игровые роли (четвёртая выполнена первым агентом
отдельным заданием). Использованы try-engine и fix-engine-after-developers.

Это прицельный повтор новых тангентов/теней и прежних игровых проектов,
а не полный повтор всех функций движка. Все четыре роли прошли чистое CLI
создание, C++ сборку и реальный игровой фрагмент на финальном SDK. Старые исходники
и отчёты сохранены; обновления выполнялись в отдельных копиях.

## Исправлено

1. **BUG-R5-001:** входная GPU-сигнатура не включала TANGENT, поэтому материал
   всегда пользовался запасным вычислением через производные UV.
2. **BUG-R5-002:** зеркальная world matrix не меняла знак tangent basis — normal
   map получала перевёрнутую бинормаль. Обе ошибки воспроизведены отдельно на
   настоящих пикселях WARP до правок; после исправления проверки проходят.
3. **BUG-R5-003:** commandlet host не передавал PointLightV2. Одиночное duplicate
   теряло castShadows, затем Save/Load закреплял потерю. Исправлено подключение
   расширения, повторён исходный агентский сценарий и независимая регрессия.
   Ошибка обычного GUI-дублирования этим сценарием не установлена.

Все три подтверждённых дефекта исправлены. Экстренных исправлений Engine/SDK,
без которых невозможно собрать пользовательский C++-проект, не потребовалось.
MSVC C1902/LNK1101 в sandbox и старые timestamps при копировании Source — отдельные
проблемы окружения/подготовки; исходная диагностика сохранена.

Добавлены mesh.tangents, TangentCommandletTests, PointLightCloneCommandletTests,
GPU regression и проверка восстановления тангентов через SaveGame. Обновлены
MATERIALS, COMMANDLETS, ENGINE-VERSIONS, API Reference и трекеры 063–065.
Подробные причины и команды: [issues.md](issues.md), [fixes](fixes/README.md).

## Покрытие и ограничения

В [матрице](feature-matrix.csv) 95 обнаруженных пунктов каталога. Два разработчика
практически попробовали **24**, из них **11** имеют два успешных результата по
проверенному сценарию. Partial не означает полную проверку подсистемы. Остальные
**71** пункта не набрали двух попыток; полный перечень в [coverage.json](coverage.json).
Недоступная команда «создать сразу C++ проект» из старой матрицы исключена:
поддерживаемый CLI — create-project → enable-code.

Не заявляются: полный визуальный Edit/Game прогон четырёх проектов, resize каждого
игрового UI, отсутствие дрожания каскадов при движении камеры, все виды point-shadow
casters/их анимации, сравнение GPU разных производителей, прослушивание аудио,
экспорт каждой игры и повтор всей старой функциональности. Снимок Qt инспектора
подтверждает раскладку; D3D child viewport в grab чёрный и не является доказательством
правильной edit-картинки. Игровые кадры ролей 1/3/4 осмотрены, у роли 2 visual-unverified.

Следующая порция: движущаяся камера и каскадные стыки; движущийся источник/кастер
в point shadows с A/B; normal map на импортированной модели в редакторе; game/editor
resize и экспорт этих четырёх сохранённых проектов.

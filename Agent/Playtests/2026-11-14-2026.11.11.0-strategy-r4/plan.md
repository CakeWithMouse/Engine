# Repair Corridor r4: рамка и групповая атака

Тот же strategy_developer продолжает проверенный исходный архив r3 в отдельном
`Engine/build/playtests/strategy-r4/RepairCorridor`. База — main `87a9cf85`,
Engine 2026.11.11.0, SDK SHA256
`18622FC582C05F0DEC25753C4297C3276C44C736D764FBFDA460D2E56F35B1B3`.

По запросу пользователя работает только этот разработчик. Он добавляет рамочное
выделение и команды атаки выбранному отряду; необходимые API получает по запросу.
Координатор исправляет подтверждённые дефекты движка, автор повторяет исходные
сценарии на обновлённом SDK. Правила боя остаются в игровом проекте.

Критерии: рамка в обе стороны, Shift-добавление, обычный щелчок, пустое выделение,
HUD и resize; реальный урон и завершение атаки, подход к цели, независимость
невыбранных, отмена/замена приказа и недействительная цель. Проверки через реальный
ввод и Play, визуальные свидетельства и телеметрия; затем source ZIP, свежая
распаковка/сборка/Play и standalone. Старые архивы и доказательства не меняются.

# Отзыв — роль 1, «Спокойный город»

Штатное создание проекта и подключение C++ через SDK работают. По снимкам координатора теперь подтверждены хороший ракурс города, читаемая теневая сцена и движение машинки по дороге. Для игровой механики хватило `Tick` и свойств компонента; API Reference помог с локальными преобразованиями, иерархией и направлением примитива Plane. Ошибки в C++ сборке и форматировании сцены были понятными и исправимыми.

В отдельном probe публичные API успешно проверили геометрию машинки: валидатор нашёл UV и корректный pivot, упрощатель сократил mesh с 344 до 188 треугольников, генератор создал два LOD с нулевым silhouette drift. Startup smoke также подтвердил запуск FXAA. Это консольная проверка; сами инстансы и цвета отладки LOD на скриншоте ещё не смотрели.

Главная незакрытая неудобность — узкие поля Inspector обрезают содержимое (BUG001, воспроизводится также у ролей 2 и 3). Поле скорости `CarMover` через UI пока не менялось; сериализованное значение `3.25` подтверждено в сцене, но это ещё не UI round-trip. Проба старой замороженной DLL завершилась exit 1 без диагностического лога на headless пути, поэтому совместимость не считаю подтверждённой; нужна интерактивная проверка штатного сценария.

Проверил замороженную DLL выпуска 2026.10.24.0 из официального fixture `lights.zip`: все семь файлов совпали с SHA256SUMS, `--check-project` и запуск `EngineLauncher --smoke-project-current` на нынешнем runtime завершились с кодом 0, хэш DLL после запуска сохранился. Обычный прямой запуск runtime отказал из-за старого pin и предложил идти через launcher; это ожидаемая защита. Интерактивный выбор старой версии и upgrade prompt оставлены за рамками CPU/CLI-прохода.


## Финальные наблюдения координатора

Итог координатора: новая DLL8d5c3a успешно загружена в том же окне с несохранённым зданием x=-7.5; аварийное восстановление вернуло его. Перенос по оси с шагом0.5 и UI редактора материала (preview/lit/unlit/save/revert) подтверждены. Старый frozen lights прошёл forced-current smoke; выбор старого runtime остаётся непроверенным.

# Промпт: понятный CLI создания C++-проекта

Работай в текущей ветке PainEngine, сохраняя ранее сделанные изменения. Исправь подтверждённые затруднения автора Curious City при работе с EngineLauncher.

1. Добавь `--help` с поддерживаемыми командами и точной последовательностью `--create-project <новая папка> <имя>` → `--enable-code <Project.json>` → `--build-project <Project.json>`. Укажи требования MSVC/Windows SDK/SDK закреплённого runtime и местоположение CodeBuild.log.
2. При неизвестной команде или неверном числе аргументов выводи объяснение в stderr и возвращай exit 2. Для неподдерживаемого `--create-code-project` покажи штатную альтернативу, не добавляя новую команду.
3. При ошибке операции возвращай exit 1 и читаемую диагностику. Конфликт существующего каталога должен содержать абсолютный путь и требование новой папки. Существующие данные не изменяй. `--help` возвращает 0 и пишет только stdout.
4. Обеспечь читаемую консоль и UTF-8 при перенаправлении, включая пробелы и кириллицу. CLI не должен открывать MessageBox; обычный GUI-запуск сохраняет текущий интерфейс. Учти Windows GUI subsystem: сохраняй перенаправленные handles и документируй ожидание завершения процесса в PowerShell.
5. Добавь интеграционный runner: help, неизвестная команда, неверные аргументы, отсутствующий проект, существующая папка с неизменным файлом-маркером, успешное создание, включение C++, сборка и smoke. Проверь stdout/stderr и exit code, изолируй проекты и EngineStore. Зафиксируй результаты до/после.
6. Обнови релевантные документы: отдельное руководство CLI, ссылки из создания C++ проекта/быстрого старта, API Reference и документации тестов по необходимости. Примеры должны запускаться в PowerShell без скрытой зависимости от текущей папки.

Не реализуй экономику, новые property API, Raycast, спавн, recovery, систему сохранения игры или wishlist. Это отдельные задачи. Не меняй контракт владения AddComponent. Выполни сборку Release и необходимые регрессии, сохрани отчёт с точными результатами. Систему SaveGame затем только спроектируй отдельным документом и HTML-схемой, явно обозначив проектные API как ещё не реализованные.

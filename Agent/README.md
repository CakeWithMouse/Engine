# Материалы агента

- [AGENTS.md](AGENTS.md) — постоянный контекст проекта и правила работы.
- [engine-developer.md](engine-developer.md) — профиль разработчика движка.
- [Tasks](Tasks/README.md) — задачи, выполненные проверки и будущие улучшения.
- `Reviews` — исходные разборы кода.
- `Archive/previous-build` — сохранённые результаты старой сборки; не используются и не индексируются Git.

При запуске новой задачи указывайте: «Сначала прочитай Agent/AGENTS.md и Agent/engine-developer.md». В корне репозитория AGENTS.md больше нет; произвольный путь Agent/AGENTS.md не заменяет стандартное автоматическое обнаружение корневого файла. Текущие пользовательские инструкции важнее сохранённых правил.

Рабочий код находится в Engine и Game. Исторические команды в завершённых задачах описывают расположение на момент их выполнения; актуальная структура — в [документации](../Engine/docs/FOLDER-ARCHITECTURE.md).

# 075 — Видимость камеры и расстояния во вьюпорте

Выполнено 2026-11-14 в ветке feat/camera-viewport-ux, поверх main 0947535.

Проблемы: камера имела только billboard; направление и границы кадра отсутствовали; инспектор намеренно скрывал свойства класса у камер; overlay обновлялся только при фокусе во вьюпорте, поэтому изменение параметров в инспекторе не отражалось сразу.

Добавлено: объёмный маркер камеры со стрелкой и обозначением верха; для выделенной камеры — ближняя рамка, границы обзора, срез на заданной глубине и десять отметок расстояния. Поддержаны перспектива, ортографическая проекция, viewPlane и мировая трансформация камеры с учётом родителей/inheritScale. Billboard камеры также учитывает мировую позицию при отрисовке и выборе. Существующая логика манипуляторов трансформации не изменена.

Карточка «Обзор камеры» показывает Near/Far, размеры кадра на заданной глубине, шаг шкалы, расстояние от вида редактора и пересечение центрального луча с плоскостью Y=0 (это не raycast по геометрии). Есть глубина схемы без изменения Far Clip, полная дальность, x-ray, общий выключатель и «Найти камеру · F». Параметры проекции снова доступны через существующие свойства класса и Undo. Формат кадра берётся из текущего вьюпорта, как у текущей проекции runtime. Меню «Вид → Камеры: направление и границы» управляет отображением без выбора камеры. Обновление overlay отделено от фокуса клавиатурной навигации.

Проверено: Debug Editor.dll и EditorUiTests; CoreTests — 1105 проверок, включая математику фрустума/ортографии/родителей; EditorUiTests --camera-guides — создание камеры, доступность параметров, изменение FOV через инспектор, выключение слоёв, ортография и показ размеров. Проверено визуально при фокусе в инспекторе. Скриншоты получены из настоящего Qt/D3D-окна.

Логи: O:/Engine/Artifacts/camera-editor-build.log, camera-ui-build.log, camera-core-tests.log, camera-ui-tests-final.log. [Отчёт со скриншотами](../../Engine/docs/reports/camera-guides.html).

Воспроизведение UI-теста: собрать диагностический модуль и подготовить Fixture по Engine/tests/ai/diagnostics/README.md; передать EditorUiTests.exe флаг --camera-guides вместо --ai-diagnostics. Для ручной съёмки установить CAMERA_GUIDE_CAPTURE=1; протокол capture-ready.txt / capture-done.txt тот же.

# 038 — Автоматическое обнаружение компонентов

Первый небольшой этап 035-C. GameComponent остаётся базой; Scene не переписывается.
Автор указывает ENGINE_COMPONENT() над классом, сборка создаёт фабрики.

| Шаг | Задача и приёмка | Статус |
|---|---|---|
| 1 | Аннотация, генератор, build target, локальный каталог; новые заголовки без ручной таблицы, настоящие классы, диагностика, документация и тесты | Выполнено, Debug v143 проверен |
| 2 | Передача каталога и команд через игровой модуль/runtime; согласовать владение и ABI | [Выполнено, 039](039-scene-module-commands.md) |
| 3 | Список типов редактора, создание через Scene | UI впереди; хранение ключа типа выполнено в 039 |
| 4 | JSON и общий загрузчик на тех же фабриках; версии, неизвестные типы, связи вторым проходом, безопасная запись | Далее |
| 5 | Play из независимых экземпляров документа, Stop/Pause, миграция примеров (035-E/F) | Далее |

ENGINE_PROPERTY отложен. Геометрия/материал — только пустая ComponentVisualDefaults;
ресурсный контракт уточняется отдельно, ядро не зависит от игровых классов.

Продолжение: [COMPONENT-GENERATION.md](../../Engine/docs/COMPONENT-GENERATION.md).
Проверка: Engine/tests/component-generation/run.ps1, без редактора/окна/GPU.
Пройдены интеграция с Scene, 17 проверок сканера, 4 ожидаемые ошибки компиляции,
сборка пустого каталога. При первой пересборке Engine был прежний warning C4996
в Base.cpp (getenv); новый генератор собран без предупреждений.

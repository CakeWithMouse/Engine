# 072 — Освещение и звук в Edit, Play и отдельной игре

## Причины и исправления

- `SceneModule.inl`: начальный Game получал сценовый режим освещения, но загрузчик
  startupScene заменял его результатом пользовательской фабрики без повторного
  `SetSceneLightingEnabled(true)`. У C++-проектов возвращались скрытая ambient-подсветка
  и старый режим материалов. Теперь настройка применяется и к загруженному Game.
- `SceneEditSession`: Game редактора остаётся жив во время Play, поэтому его
  предпрослушивание продолжало звучать одновременно с игрой. При успешном переходе
  в Play предпрослушивание останавливается.
- Pause и остановка симуляции после исключения Tick теперь приостанавливают XAudio2
  соответствующего Game. Resume возобновляет обработку без потери позиции.
  Неудачный StartEngine оставляет сессию на паузе. Stop уничтожает игровое аудио;
  следующий Play создаёт работающий экземпляр.

## Проверка

`Engine/tests/edit-session/ModeParityTests.cpp` использует общий SceneModule с
пользовательской фабрикой Game и настоящий загрузчик сохранённой сцены.

- Четыре состояния: без источников, направленный свет, выключенный направленный
  свет, точечный свет; Forward и Deferred; Edit, Play, отдельное скрытое окно.
- 24 BMP совпадают побайтно при одинаковой камере, размере и настройках AA.
- Возврат старого режима на том же Game воспроизводит расхождение изображения.
- На настоящем XAudio2 проверены остановка предпрослушивания при Play, заморозка
  SamplesPlayed на Pause и после исключения Tick, продолжение после Resume,
  Stop из паузы и повторный Play. Звук проверки беззвучный, WAV создаётся тестом.
- Набор EditSessionTests: 651 проверка; Debug и Release прошли. При общей
  пересборке 2026-11-08 полная матрица из 24 кадров проверена в обеих конфигурациях.
- Release runtime и SDK пересобраны в `Game/build/x64/Release/Runtime`.
  SDK собран базовым v142; проверки заголовков и whole-archive link прошли
  на v142, v143, v145. SHA-256 опубликованной Engine.lib совпадает с Sdk.json.

Артефакты: `Engine/build/mode-parity/`, журналы в `O:/Engine/mode-parity-*.log`.

## Применение

Исправление загрузчика компилируется в Game.dll; замены одного EngineRuntime.exe
недостаточно. Для существующего C++-проекта нужна пересборка Game.dll с обновлёнными
заголовками и Engine.lib из SDK. Старые распакованные сборки автоматически не меняются.

Конкретный пользовательский проект и точный симптом звуковой ошибки не были указаны;
проверены воспроизводимые ошибки общего пути Edit/Play/Game.

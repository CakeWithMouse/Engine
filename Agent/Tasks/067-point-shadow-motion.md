# 067 — Точечные тени: движение света и анимации

Проверка и выпуск 2026.11.07.2. Свидетельства и финальные результаты:
[отчёт](../Playtests/2026-11-07-point-shadows/report.md).

- Воспроизведено пропадание VAT-тени при выходе позы за bind sphere:
  обычный skeletal caster пишет +X грань, VAT — нет.
- Bake вычисляет envelope всех поз с квантованными весами. Радиус применяется
  к отсечению и не меняет выбор screen LOD. Неизвестные bounds внешней VAT
  консервативно отключают геометрическое отсечение.
- Воспроизведено отсутствие point cube в сцене без солнца. Инициализация,
  привязка ресурсов и point caster streams теперь независимы от каскадов.
- GPU-командлет и регрессия: движение лампы/меша/кости, возврат состояния,
  on/off, cube seam, radius culling, импорт CesiumMan, Forward/Deferred.
- Документация: RENDERING, COMMANDLETS, ENGINE-VERSIONS, API Reference.

# 053 — Игрок и камера в свойствах

Реализовано 2026-11-01.

- В стандартном каталоге появился Gameplay.Player (PlayerCharacter). Gameplay.Character остаётся NPC по умолчанию; флаг «Игрок» включает possession у любого наследника Character. Несколько активных игроков дают явную ошибку, а не случайный выбор.
- В свойствах персонажа: роль игрока, стандартное управление, скорость, ссылка на камеру, дистанция, высота, чувствительность, перспектива/ортография, FOV, near/far, высота ортографического вида и XY/XZ/YZ. Общий CameraProperties задаёт параметры проекции. С назначенной отдельной SceneCamera используются её свойства и трансформация; без ссылки работает камера слежения игрока.
- Стандартное движение согласовано с выбранной 2D-плоскостью. При отсутствии игрока SceneEditSession сохраняет вид камеры редактора. Отдельная камера без игрока не активируется. Stop возвращает редакторскую сцену и камеру.
- Удалены Configure Play из меню и кнопка конфигурации с верхней панели. Настройки находятся в группах «Игрок» и «Камера игрока» в инспекторе. Исторические PlaySettings остаются скрытыми сервисными записями для совместимости.
- SceneDocument::Restore после remap переносит старые PlaySettings в Character, чьи сохранённые данные ещё не содержат playerControlled. Последующее сохранение фиксирует новые свойства; историческая запись их не перетирает. Камерные ссылки учитывают удаление/переназначение ID. Ссылка в инспекторе фильтруется по gameplayKind, поэтому доступны пользовательские типы камер, а посторонние типы отклоняются.
- Разрешён имеющийся конфликт слияния CompatibilityTests: ожидаемый формат теперь берётся у целевого модуля, без жёсткого выбора между форматами 2 и 3.

# 048 Частицы, скайбокс, категории и видимое выделение

Дата: 2026-10-26. Реализовано для выпуска 2026.10.26.0.

## Поведение

- Стандартные `Particle.Sparks`, `Particle.Smoke`, `Environment.Sky` доступны в проектах без кода и через SDK в проектах с C++.
- Искры и дым используют существующий GPU emitter. Небо — градиентный shader без текстур, рисуется на дальней плоскости, не закрывает геометрию и не перехватывает picking.
- Панель создания: категория → тип → одна кнопка добавления; модели/импорт объединены в меню. Категории: примитивы, свет, частицы, окружение, классы проекта, все.
- Выделение через ЛКМ, иерархию или Tab: золотистая рамка world bounds во viewport, подсвеченная строка, имя/тип/ID в инспекторе. Esc и пустой клик снимают выбор. У света и emitter рамка отмечает место объекта, у sky — компактный маркер.
- Выделение — состояние редактора, не материал или часть сцены. Play не показывает рамку; удалённый ID не хранит указатель на объект.
- Отдельное расширение `Engine.Editor.Selection` v1; размеры существующих Module/Edit/Scene API не изменены. Старые DLL продолжают открываться без нового расширения.
- Edit preview тикает только базовую GPU-симуляцию частиц, без пользовательских gameplay overrides. Play использует шаг симуляции Game. GPU dispatch потребляет шаг один раз, Pause не повторяет его.
- Сохранение/Play copy восстанавливают пресет и трансформацию, живые частицы не сериализуются.

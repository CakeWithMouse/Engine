# 061 — Завершённая статистика кадра и диагностика LOD

Запрос пользователя: сделать удобные инструменты для автора бомбардировки, обновить
документацию, проверить тестами и дать той же персоне повторный прогон.

Реализованы GetCompletedFrameStats (valid/frameIndex/counters/lodComponents), снимок после
основных render passes и панель F7/F8. У LOD есть уникально видимые экземпляры, скрытые,
отсечённые дистанцией/frustum, диапазон дистанций, пороги, per-LOD buckets и sprite marker.
Fade не удваивает unique drawn; отсутствующие данные текущего кадра помечаются unavailable.
Панель не входит в сцену/SaveGame, не захватывает ввод и исключена из своих counters.

Новый SDK: 2026.11.05.1. C ABI не менялся. Документация:
[RENDER-DIAGNOSTICS](../../Engine/docs/RENDER-DIAGNOSTICS.md), API Reference и SDK/Docs.

Проверки и пользовательский результат: [отчёт](../Playtests/2026-11-05-lod/report.md).
Новые исходники и результаты не опубликованы в EngineStore и не закоммичены этим заданием.

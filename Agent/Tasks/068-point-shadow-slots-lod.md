# 068 — Две теневые лампы, слоты и анимированные LOD

Выпуск 2026.11.07.3. [Отчёт и воспроизведение](../Playtests/2026-11-07-two-lights/report.md).

- Воспроизведено: лампа с intensity=0 занимала слот, третья светила без тени.
  Единый predicate отбора карт и shader binding теперь исключает такие лампы.
- Воспроизведено: цвет смешивал соседние LOD, point depth оставался у старого
  силуэта и резко переключался в конце полосы. Теперь оба mesh caster несут
  тот же signed fade; instanced material depth shader применяет dither.
- Legacy-инстансы используют стандартный материал только для depth pass;
  назначенные материалы проверяют наличие шейдера фактического варианта.
- GPU-командлет читает обе карты, реальные shader slots и LOD diagnostics;
  регрессия проверяет смену/освобождение слотов, два mesh LOD-перехода,
  назначенный материал, CesiumMan и совместное движение камеры/света/позы.
- Сохранены старые сценарии движения одной лампы и совместимость проектов.

Distance LOD без fade остаётся дискретным. Солнечные тени используют один LOD;
при переходе в impostor точечная тень сохраняет последний mesh caster.
Обычный skeletal-компонент не имеет LOD API.

# 035 — Сцены как данные и встроенный Play

Решение автора: Scene в ядре, JSON-файлы, встроенный Play с отдельной игровой копией.
Небольшие этапы, без ECS и полной переписи рендера.

| Этап | Задача | Приёмка | Статус |
|---|---|---|---|
| A | [Разделение симуляции и отображения](036-editor-preview-play.md) | Статичный Edit; Space запускает/откатывает, P замораживает/продолжает | Выполнено, Debug проверен |
| B | Scene и SceneObject в Engine | ID, иерархия, владение, создание/удаление без GPU; адаптация GameComponent | Запланировано |
| C | Реестр типов/свойств и JSON | Версии, связи вторым проходом, сохранение неизвестных данных, безопасная запись | Запланировано |
| D | Документ и инструменты редактора | Hierarchy, Inspector, transform, создание/удаление/дублирование, Undo/Redo, Save/Save As | Запланировано |
| E | Play из снимка текущих данных | Несохранённые правки в копии; BeginPlay/EndPlay, отдельное время/ввод; Stop сохраняет документ | Запланировано |
| F | Миграция примеров | BasicExamples, затем Pong используют файлы сцен и зарегистрированные игровые типы | Запланировано |
| G | Несколько сцен и standalone | Несколько файлов, одна активная сцена; startupScene/defaultEditorScene; общий загрузчик редактора и игры | Запланировано |

Engine владеет сценами, ресурсами и симуляцией. Editor содержит документы, UI и историю
команд. Game определяет типы и правила; регистрация типов не запускает игру.
UI посылает команды в поток движка и получает результаты/снимки, не указатели на объекты.
Сериализуются начальные данные и ссылки, не GPU-объекты, указатели и текущий счёт игры.
Вкладки, additive-сцены, Apply Play Changes и hot reload живых объектов отложены.

Поток: Project → JSON → редактируемая Scene → снимок в памяти → игровая Scene.
Редактируемая Scene → сериализация → JSON. Stop уничтожает только игровую Scene.
Renderer отображает активную сцену; обновление изображения не запускает игровой Tick.

Промежуточный этап A использует построители вместо снимка данных: это ещё не JSON
и не копирование произвольных изменений сцены.

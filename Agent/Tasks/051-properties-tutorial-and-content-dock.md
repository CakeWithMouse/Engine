# 051 — Проект-туториал и панель контента

Запрос: готовый проект с кастомным свойством; исправить неудобное перемещение панели контента.

- Готовый пользовательский проект: `O:/Engine/Проекты/Туториал-Свойства`.
- Исходники примера и создание новой копии: `Game/PropertyTutorial/Create.ps1`.
- Два RotatingCube: разные скорость и яркость; скорость/включение влияют на Play,
  яркость применяется сразу в Edit. README связывает поля с codec и schema.
- Разделитель панелей расширен до 9 логических пикселей с подсветкой.
- «Вид»: компактная панель ресурсов, отдельное окно, сброс расположения.
- Имена dock/toolbar стабильны, раскладка хранится отдельно для каждого проекта.
- QMainWindow с полностью dock-based рабочей областью отдавал почти всю новую
  высоту нижним вкладкам; теперь при resize сохраняется выбранная высота контента.
  Изменение размеров выполняется после расчёта layout и задаёт размеры верхнего
  ряда вместе с нижней группой; один resizeDocks для вкладки эффекта не давал.

Проверено Release: drag разделителя, увеличение окна, floating/docking,
сброс и round-trip раскладки — 140 проверок; туториал / яркость / Undo / Play — 363.

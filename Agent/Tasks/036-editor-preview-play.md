# 036 / 035-A — Статичный редактор, Play/Stop и Pause

Статус: выполнено, Debug проверен. Согласовано автором 2026-10-17.

## Поведение

- Edit: сцена видна; игровое время, PreUpdate, Tick и GPU-симуляция остановлены.
- Space в фокусе viewport: Edit → Play; Play/Pause → Edit с исходной сценой.
- P, включая физическую клавишу в русской раскладке: Play ↔ Pause; в Edit ничего.
- Pause сохраняет экземпляр, данные и время; камера и UI доступны.
- Автоповтор не переключает режимы; текстовые поля не управляют игрой.

## Изменения

- Разделить Game::UpdateFrame на симуляцию и подготовку изображения.
- Частицы: остановить compute-симуляцию, сохранить сортировку для камеры.
- ViewportSession удерживает исходный Game и игровой Game от фабрики.
  Device/context/swap chain общие; back-buffer views только у активной сцены.
  Stop освобождает игровую сцену; исходные объекты и камера остаются в памяти.
- ABI v4: очередь Qt → host; статус UI через atomic.
- Пока остаётся редакторская навигация. Игровой ввод, Scene/JSON, BeginPlay/EndPlay
  и снимки изменённых данных — следующие этапы.

## Приёмка

- Статичные transforms/пиксели в Edit; логика работает в Play.
- Pause не пересоздаёт объекты и не меняет симуляцию; Resume продолжает её.
- Повторные Play/Stop возвращают исходные объекты и камеру.
- Resize в Play/Pause и возврат в Edit работают.
- Ошибка построения Play оставляет рабочую исходную сцену.
- GPU-частицы не симулируются при выключенном игровом обновлении.
- Проверки движка, viewport, runtime и Qt проходят.

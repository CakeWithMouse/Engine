# 046 — Импорт моделей и текстур в редактор сцены

- Files: импорт моделей GLB/glTF/OBJ/FBX и текстур PNG/JPG/BMP/TGA; создание модели и назначение текстуры двойным щелчком/контекстным меню.
- Инспектор: пути модели и текстуры, выбор текстуры из проекта, снятие назначения.
- Scene: переносимые ссылки `/Game/...`, необязательный блок `assets` в JSON v1, восстановление ресурсов при загрузке/Play/Undo/Redo/дублировании.
- Импорт: без перезаписи существующих файлов, валидация изображения и модели, перенос внешних glTF buffers/images, откат неудавшейся копии.
- Runtime: Edit API v4 и Scene API v2; проектный Content настроен до чтения стартовой сцены; template-проекты получают DLL-зависимости импортёра.
- Рендер: статические меши с преобразованиями узлов, текстуры на скелетных моделях, отложенная загрузка до появления GPU, выбор/фокус по CPU-геометрии, текстуры на примитивах.
- Тесты: `Engine/tests/assets/run.ps1 -EnableAssimp`, `Editor/tests/run.ps1 -EnableAssimp`, существующие skeletal/runtime/scene/edit-session suites. Asset-тест проверяет также пиксели D3D, а не только успешный возврат API.

Пользовательский процесс, границы импортёра/материалов, обновление старых DLL и инструкция по своему C++-компоненту: [PROJECT-ASSETS](../../Engine/docs/PROJECT-ASSETS.md).

Проверено в Debug, MSVC v145, Qt 6.7.3:

- Asset workflow с Assimp: 68 проверок; без Assimp: 51.
- Qt UI: 897 проверок (включая импорт модели и сохранение снимка интерфейса).
- Skeletal: 8/8; Engine: 29/29; Scene API: 109; Edit API: 609.
- Project workflow: 59 проверок, затем запуск сохранённого проекта в game/editor.
- Runtime: 25 проверок.

Зависимости Assimp и Qt установлены в игнорируемые каталоги; итоговая Debug-сборка поддерживает импорт моделей. Release в рамках задачи не проверялся.

Уточнение интерфейса: в панели сцены и меню добавлены явные действия добавления модели из проекта и импорта. Ошибки пустого файла и превышения 256 MiB разделены; превышение сообщает фактический размер и путь. Проверка размера больше не читает модель/зависимость целиком перед импортом. Повторная проверка: Asset workflow — 71, Qt UI — 898.

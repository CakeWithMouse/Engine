# 049 — Сохранение, совместимость, экспорт, группы

Пользователь заказал пункты 1–3 пользовательского аудита и обязательный запуск
редактора/игры старого проекта на новой версии PainEngine.

Реализация:
- отдельные Save и назначение startupScene;
- автосохранение изменённой Edit-сцены, журнал восстановления и блокировки сессий;
- обычные Играть/Редактировать предлагают обновление копии старого закреплённого проекта;
- диагностический запуск на текущем runtime с исходной DLL сохранён в CLI;
- адаптер исторического Scene API 3 для игрового запуска (Edit API 5 уже адаптировался);
- экспорт в новую папку после проверки сцен и standalone, полный Content и DLL Visual C++;
- множественное выделение, атомарные группы, привязки, одно Undo на drag;
- необязательное Batch API без изменения исторических Edit API;
- выпуск 2026.10.31.0, новая C++ SDK ABI требует пересборки.

Инструкция: Engine/docs/RELIABLE-WORKFLOW.md.
Проверки 2026-10-31:
- ядро: 44/44, включая группу из 100 объектов, перемещение/поворот/масштаб,
  родителя и ребёнка, отклонение некорректной операции, перенос ссылок между копиями;
- исторические DLL: 96 проверок, игровой и редакторский запуск закреплённого
  старого проекта на новом runtime; Project.json, Engine.lock.json и DLL не изменены;
- исторический Qt-редактор: 373 проверки;
- полный актуальный Qt-сценарий с Assimp: 2400 проверок;
- Hot Reload: 37 проверок, в том числе новая batch-сессия после выгрузки старой DLL;
- интеграционный workflow: выбор группы в иерархии, одно Undo на drag, Redo,
  Save без изменения startupScene, отдельное назначение стартовой сцены,
  завершение тестового процесса и восстановление в новом процессе,
  запуск экспорта при перемещённом исходном проекте, отказы при перезаписи,
  вложенном назначении, потерянной и выходящей за Content зависимости.

Логи: O:/Engine/target/workflow-123. Проверка на чистом Windows-компьютере
не проводилась. Восстановление относится к сцене, а не к незаписанным черновикам
HLSL/материалов. Групповые функции требуют нового необязательного API игровой DLL.

Уточнение пользователя: отдельные команды «Играть/Редактировать на текущем движке»
убраны из меню. При запуске старого проекта показываются версии, путь копии и варианты
обновления / прежней версии / отмены. Проверено через настоящий диалог лаунчера:
отмена, согласие в game/editor, сохранность оригинала, отсутствие повторного вопроса
у обновлённой копии, отказ при неизвестной версии сцены. Скрипт:
Engine/tests/compatibility/upgrade-prompt.ps1.

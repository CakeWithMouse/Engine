# 045 — Пользовательские проекты и инструменты сцены

Реализован путь «создать проект → собрать сцену из примитивов → сохранить → запустить».

- Лаунчер: создание в новой папке без перезаписи, открытие Project.json, постоянный список, редактор и standalone запуск.
- SceneProject: готовый модуль с кубом, сферой, плоскостью, цилиндром, конусом и пирамидой. Стартовая сцена содержит землю и куб. Персональный проект не требует компиляции.
- Editor: палитра и точка добавления, hierarchy, inspector, имя/позиция/поворот/масштаб, дублирование/удаление, выбор треугольников ЛКМ, фокус F, свободная камера независимо от выделения.
- Документы: New/Open/Save/Save As, обновление startupScene, ошибки записи/чтения, защита несохранённых изменений, Undo/Redo до 64 снимков.
- Edit API v3: picking/focus, viewport и Play подключены к edit session. Старые preview-сцены остаются совместимы по прежнему пути.
- Потоки: команды выполняются на потоке движка; UI получает копию снимка и результат через Qt. Play использует отдельную копию, а standalone запускает сохранённую стартовую сцену.

Проверено x64/MSVC v143:

- `Engine/tests/project-workflow/run.ps1`: Debug и Release, по 59 проверок и отдельные game/editor smoke через лаунчер. Включает Unicode/пробелы в пути, отказ перезаписи, все примитивы, D3D, picking/focus, JSON round trip, неверный документ, Play/Pause/Stop.
- `Engine/tests/edit-session/run.ps1`: 575 существующих проверок.
- `Editor/tests/run.ps1`: Debug и Release, реальный Qt UI, добавление/свойства/Undo/Redo/Save/Play/Stop, запрос сохранения при закрытии и Cancel; Ctrl+S в активном поле, очередь Add → New. Отдельная копия проекта, пользовательский реестр не меняется.

Руководство: [USER-PROJECTS](../../Engine/docs/USER-PROJECTS.md).

За рамками этого этапа: физика, игровые правила, пользовательские материалы и transform gizmo. Данные проекта уже пригодны для дальнейшего расширения каталога типов.

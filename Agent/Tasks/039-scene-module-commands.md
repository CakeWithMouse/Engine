# 039 — Каталог игрового модуля и команды Scene

Выполнено 2026-10-18, Debug v143.

- RuntimeExample подключён к генератору, содержит обычный ENGINE_COMPONENT Mover.
- SceneCommands внутри DLL перечисляет каталог, создаёт/удаляет/переименовывает
  объекты, задаёт transform и возвращает копируемые снимки.
- Необязательный EngineGetSceneApi v1; ModuleApi v4 сохранён. Runtime проверяет
  расширение после start и очищает таблицу до stop/destroy/unload.
- Scene копирует ключ типа в компонент и snapshot. Прежние добавления совместимы
  с пустым ключом. C++-объекты и владение не передаются через ABI.
- Тесты без редактора: 109 проверок моста, настоящего DLL и runtime; 13/13 ядра.

Контракт, примеры, владение и инструкция следующему агенту:
[SCENE-MODULE-API.md](../../Engine/docs/SCENE-MODULE-API.md).

Осталось: игровая edit-сессия рядом с Editor.dll, host-маршрутизация команд,
UI типов/Hierarchy, привязка отображения, JSON и Play-копия. Нынешний preview использует
свою сцену; этот этап его не заменяет. Геометрия/материал и ENGINE_PROPERTY отложены.
